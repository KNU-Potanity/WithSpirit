# 캐릭터 컨트롤 스펙 문서 — MVP

## 0. 문서 목적

이 문서는 `플랫포머_게임_기획서_MVP.md`에서 "있다/없다"로만 정의된 이동·점프 기능에 **구체적인 수치**를 부여합니다.

- 여기 적힌 값은 **1차 추정치(초안)**이며, 프로토타입 제작 후 실제 플레이 테스트를 통해 조정하는 것을 전제로 합니다.
- `레벨디자인_MVP_스테이지1.md`의 타일 단위(갭 1~2타일, 클라이맥스 구간의 큰 갭)와 호환되도록 수치를 맞췄습니다.

---

## 1. 기준 단위

| 항목 | 값 | 비고 |
|---|---|---|
| 프레임레이트 | 60 FPS | 모든 시간 수치는 이 기준으로 환산 |
| 1 타일 | 64px | 레벨 디자인 문서의 "1칸"과 동일 |
| 캐릭터 히트박스 | 가로 0.8타일 × 세로 1.5타일 (약 51×96px) | 발판/장애물보다 살짝 작게 잡아 시각적 여유 확보 |

> 캐릭터 히트박스를 시각적 크기보다 약간 작게 잡는 것은 플랫포머에서 흔히 쓰는 기법으로, 플레이어가 "분명히 피했는데 맞았다"고 느끼는 것을 줄여줍니다.

---

## 2. 이동 (좌우 이동) 스펙

| 항목 | 값 |
|---|---|
| 최고 이동 속도 | 6.0 타일/초 (384 px/s) |
| 최고 속도까지 가속 시간 | 0.15초 (9프레임) |
| 정지까지 감속 시간 | 0.10초 (6프레임) |
| 방향 전환 시 감속/재가속 | 정지와 동일한 감속 후 재가속 적용 |

> 감속을 가속보다 짧게 잡은 이유: 멈춰야 할 때(장애물 직전) 빠르게 반응하는 느낌을 주기 위함입니다. 너무 미끄러지면 정밀 점프 구간(레벨 디자인 구간③)에서 불공정하게 느껴질 수 있습니다.

---

## 3. 점프 스펙

### 3.1 기본 점프
| 항목 | 값 |
|---|---|
| 최대 점프 높이 | 3.0 타일 (192px) |
| 최대 점프 높이까지 도달 시간 | 0.35초 |
| 최대 점프 시 수평 이동 거리 (최고 속도 유지 기준) | 약 4.5~5.0 타일 |

### 3.2 가변 점프 (Variable Jump)
| 항목 | 값 |
|---|---|
| 점프 버튼 짧게 입력(탭) 시 최소 높이 | 1.2 타일 |
| 점프 버튼을 떼는 순간 상승 속도 감쇠율 | 약 50% 즉시 감소 |

> 가변 점프는 MVP 핵심 기획서의 "기본 점프" 항목 안에 포함된 세부 사양입니다. 별도 확장 기능이 아니라, 점프 자체의 기본 동작으로 취급합니다.

### 3.3 코요테 타임
| 항목 | 값 |
|---|---|
| 적용 시간 | 0.12초 (7~8프레임) |
| 적용 조건 | 발판에서 떨어진 직후, 점프 입력이 없었던 경우에만 |

## 4. 레벨 디자인과의 매칭 확인

`레벨디자인_MVP_스테이지1.md`에서 정의한 구간별 갭 크기와 위 점프 스펙이 맞는지 확인합니다.

| 구간 | 갭 크기 | 점프로 커버 가능한가 |
|---|---|---|
| ② 기본 점프 구간 | 1~2타일 | 최대 수평 거리 4.5~5타일이므로 여유 있게 커버 가능 |
| ③ 정밀 점프 구간 | 갭 + 가시 조합 | 가변 점프(짧은 점프)로 정밀 조정 가능 |
| ④ 응용 구간 | 갭+가시 연속 | 최고 속도 유지 시 문제 없음, 다만 연속 입력 난이도는 플레이테스트 필요 |
| ⑤ 마무리 구간 (클라이맥스) | "가장 넓은 갭" | 최대 점프 거리(약 5타일)에 근접하게 설계해 도전적인 느낌 의도 |

> ⑤구간의 갭이 4.5~5타일을 초과하면 클리어가 불가능해지므로, 레벨 디자인 문서의 좌표를 이 수치에 맞춰 4.5타일 전후로 조정해야 합니다.

## 5. 즉사 장애물 판정

| 항목 | 값 |
|---|---|
| 가시(스파이크) 판정 영역 | 시각적 크기와 동일 (여유를 두지 않음 — 위험 요소는 명확하게) |
| 낭떠러지(추락) 판정 | 화면 하단 경계 이탈 시 즉시 리스폰 처리 |

> 장애물 판정은 캐릭터 히트박스처럼 여유를 주지 않습니다. "안전한 것(이동/점프)은 너그럽게, 위험한 것(장애물)은 명확하게"가 일반적인 플랫포머 판정 원칙입니다.

## 7. 다음 단계 (튜닝 절차)

1. 위 수치를 그대로 프로토타입에 적용
2. `레벨디자인_MVP_스테이지1.md`의 구간②~⑤를 실제 플레이하며 다음을 확인:
   - 갭을 건널 때 "여유 있다" vs "빡빡하다" 체감
   - 코요테 타임이 없을 때와 있을 때의 체감 차이
   - 가속/감속이 너무 미끄럽거나 너무 뻑뻑하지 않은지
3. 체감에 따라 수치를 ±10~20% 단위로 조정 (한 번에 너무 크게 바꾸지 않기)
4. 수치가 확정되면 이 문서를 최종본으로 갱신하고, 레벨 디자인 문서의 좌표도 함께 재조정
