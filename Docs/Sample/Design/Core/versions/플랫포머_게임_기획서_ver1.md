# 플랫포머 게임 기획서

## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 게임명 | (가제) |
| 장르 | 2D 사이드스크롤 플랫포머 |
| 플랫폼 | PC / 콘솔 (추후 결정) |
| 타겟 유저 | 캐주얼 ~ 코어 플레이어 |
| 한 줄 소개 | 정밀한 점프와 액션을 기반으로 스테이지를 클리어하는 플랫포머 게임 |
| 핵심 경험 | "정확한 타이밍과 컨트롤로 장애물을 돌파하는 쾌감" |

---

## 2. 핵심 게임플레이 (Core Gameplay)

### 2.1 이동 (Movement)
- **좌우 이동**: 일정한 가속/감속 곡선을 적용하여 발판 위에서의 미세 조작 가능
- **점프**:
  - 기본 점프 높이/거리 수치 정의 필요
  - 점프 버튼을 누른 시간에 따라 점프 높이가 달라지는 **가변 점프(Variable Jump)**
  - 발판을 벗어난 직후에도 짧게 점프가 가능한 **코요테 타임(Coyote Time)** (예: 0.1~0.15초)
- **추가 이동 기술** (선택 적용)
  - 더블 점프
  - 대시 (지상/공중)
  - 벽 점프 / 벽 타기

### 2.2 공격 / 상호작용
- 적 처치 방식: 밟기(스톰프) / 근접 공격 / 원거리 공격 중 1개 이상 채택
- 오브젝트 상호작용: 스위치, 레버, 부서지는 발판 등

### 2.3 카메라
- 플레이어 캐릭터를 화면 중앙 기준으로 추적
- 화면 경계에서의 카메라 정지/스크롤 규칙 정의

---

## 3. 레벨 디자인 요소

| 요소 | 설명 |
|---|---|
| 일반 발판 | 기본 이동 가능 지형 |
| 함정 발판 | 시간이 지나면 사라지거나 무너지는 발판 |
| 이동 발판 | 좌우/상하로 움직이는 발판 |
| 스프링/트램펄린 | 플레이어를 강하게 튕겨 올리는 오브젝트 |
| 가시/용암 등 즉사 장애물 | 접촉 시 즉시 사망 처리 |
| 체크포인트 | 스테이지 중간 리스폰 지점 |
| 비밀 구역 | 숨겨진 수집 아이템이나 추가 경로 |

### 레벨 난이도 곡선
- 1~3 스테이지: 기본 조작 학습 (이동, 점프)
- 4~6 스테이지: 신규 기술 도입 (대시, 더블 점프 등)
- 7스테이지 이상: 학습한 기술을 조합한 복합 구간

---

## 4. 적(Enemy) 시스템

| 분류 | 특징 | 처치 방식 |
|---|---|---|
| 일반 적 (지상형) | 정해진 패턴으로 좌우 이동 | 밟기 / 공격 |
| 일반 적 (비행형) | 상하 또는 추적 이동 | 공격 필요 |
| 보스 | 스테이지 종료 지점에 배치, 다단계 패턴 | 약점 공략 |

- 적 행동 패턴은 **순찰형 / 추적형 / 고정 공격형** 중 선택해 설계
- 난이도에 따라 적의 이동 속도, 공격 빈도를 조절

---

## 5. 수집 및 보상 시스템

- **코인/젬**: 스테이지 곳곳에 배치, 일정 개수 모으면 보너스 스테이지 또는 추가 생명 획득
- **숨겨진 수집품**: 스테이지 완전 탐사를 유도하는 요소 (예: 별, 카드 등)
- **스테이지 클리어 평가**: 클리어 시간, 수집률 등을 기준으로 별점/랭크 부여

---

## 6. 체력 및 생명 시스템

- **생명(Lives)**: 기본 3개 제공, 추가 생명 획득 가능
- **체력(Health)**: (선택) 단일 피격 시 즉사 대신 체력 게이지 적용 여부 결정
- **리스폰**: 체크포인트 기준으로 재시작, 수집한 아이템은 유지 또는 초기화 여부 결정
- **게임 오버 조건**: 생명이 모두 소진되면 스테이지 처음부터 재시작 또는 메인 화면 복귀

---

## 7. 파워업 시스템

| 파워업 종류 | 효과 | 지속 방식 |
|---|---|---|
| 크기 변화 | 캐릭터 크기 증가, 추가 피격 1회 허용 | 영구 (피격 시 해제) |
| 속도 강화 | 이동 속도 증가 | 일정 시간 |
| 무적 | 일정 시간 모든 피격 무시 | 일정 시간 |
| 추가 점프 | 더블 점프 등 신규 능력 획득 | 영구 또는 스테이지 한정 |

---

## 8. UI / UX

- **HUD 구성**: 남은 생명, 체력(있을 경우), 수집한 코인 수, 타이머
- **일시정지 메뉴**: 재시작, 옵션, 메인 메뉴로 나가기
- **튜토리얼**: 스테이지 1에서 텍스트 또는 비주얼 가이드로 조작법 안내

---

## 9. 사운드 / 피드백

- 점프, 착지, 수집, 피격, 적 처치 시 각각 구분되는 사운드 이펙트 필요
- 화면 흔들림(스크린 셰이크), 파티클 이펙트 등 시각적 피드백 병행
- 스테이지별 배경음악(BGM) 구성

---

## 10. 추가 고려 사항 (확장 가능 요소)

- 멀티플레이(협동/경쟁) 지원 여부
- 레벨 에디터 제공 여부
- 스토리 및 컷씬 삽입 여부
- 난이도 선택 옵션 (이지/노멀/하드)
