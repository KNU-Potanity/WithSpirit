# 에셋 출처 / 라이선스 관리

## 0. 문서 목적

이 문서는 외부에서 가져오는 그림, 사운드, 폰트 등의 에셋을 **어디서 구할지, 그리고 가져온 에셋의 출처/라이선스를 어떻게 기록할지** 정리한 문서입니다.

- 동아리 프로젝트라도 외부 에셋을 무단으로 사용하면 추후 배포/공개 시 저작권 문제가 생길 수 있어, 미리 규칙을 정해둡니다.
- `에셋_네이밍_관리규칙.md`(파일명/폴더 규칙), `사운드_큐_리스트.md`(어떤 사운드가 필요한지)와 함께 사용하는 문서입니다.

---

## 1. 기본 원칙

1. **출처가 불분명한 에셋은 사용하지 않습니다.** ("어디서 받았는지 기억 안 남" 상태의 파일은 추가하지 않기)
2. **라이선스 조건(출처 표기 필요 여부, 상업적 이용 가능 여부 등)을 반드시 확인하고 기록합니다.**
3. **저작권이 있는 캐릭터/로고/상표(다른 게임, 애니메이션, 브랜드 등)는 절대 사용하지 않습니다.** 레퍼런스로 참고만 하고, 실제 에셋은 직접 제작하거나 라이선스가 명확한 것만 사용합니다.
4. 직접 제작한 에셋(부원이 그린 그림, 만든 사운드)은 원칙적으로 문제 없지만, **누가 제작했는지는 기록**해둡니다 (나중에 수정/문의할 사람을 알아야 하므로).

---

## 2. 추천 에셋 소스 (무료/오픈 라이선스 중심)

> 아래는 시작점 예시이며, 실제 사용 전에는 항상 해당 사이트의 최신 라이선스 조건을 다시 확인합니다.

| 종류 | 사이트 예시 | 비고 |
|---|---|---|
| 스프라이트/타일셋 | Kenney.nl, OpenGameArt.org, itch.io (무료 에셋 태그) | CC0(저작권 없음) 에셋이 많아 가장 다루기 편함 |
| 사운드 효과음(SFX) | Freesound.org, Kenney.nl (오디오 팩) | Freesound는 에셋마다 라이선스가 다르므로 개별 확인 필요 |
| 배경음악(BGM) | OpenGameArt.org, itch.io, Incompetech | 출처 표기(CC-BY) 조건이 붙는 경우가 많음 |
| 폰트 | Google Fonts, itch.io (무료 폰트 태그) | 상업적 이용 가능 여부 확인 |

---

## 3. 라이선스 종류 간단 정리

| 라이선스 | 의미 | 출처 표기 필요? |
|---|---|---|
| CC0 / Public Domain | 저작권 없음, 자유 사용 | 불필요 (그래도 기록은 해두는 게 안전) |
| CC-BY | 자유 사용 가능, 단 제작자 출처 표기 필요 | 필요 |
| CC-BY-SA | 출처 표기 + 동일 라이선스로 재배포 필요 | 필요 (조건 더 엄격) |
| Royalty-Free (유료/무료 마켓) | 구매/다운로드 시 정해진 약관에 따름 | 사이트별 약관 확인 |
| All Rights Reserved | 사용 불가 (별도 허락 없이) | 사용 금지 |

> 헷갈리면 **"가장 제약이 적은 CC0 에셋 위주로 모으기"**가 제일 안전한 전략입니다.

## 4. 에셋 출처 기록 표 (사용 시마다 추가)

실제로 에셋을 가져올 때마다 아래 표에 한 줄씩 추가합니다.

| 파일명 (네이밍 규칙 적용) | 출처/제작자 | 라이선스 | 출처 표기 필요 여부 | 비고 |
|---|---|---|---|---|
| `sfx_jump.wav` | (예: Kenney.nl - Impact Sounds Pack) | CC0 | 불필요 | |
| `char_player_idle_01.png` | (예: 직접 제작 - OOO) | 자체 제작 | 불필요 | 제작자 기록 |

> 표가 길어지면 `Docs/Technical/에셋_출처_라이선스_관리.md` 파일 자체를 계속 누적해서 사용합니다. (별도 스프레드시트로 옮겨도 무방하지만, 정본은 이 문서나 저장소 내 파일로 유지)

---

## 5. 출처 표기가 필요한 경우, 어디에 표기할까

- CC-BY 등 출처 표기가 필요한 에셋이 있다면, 게임 내 **크레딧 화면**(추후 확장 기능 단계에서 추가) 또는 README 하단에 모아서 표기합니다.
- 지금 단계(MVP, 혼자 작업)에서는 크레딧 화면이 없으므로, 일단 위 4장의 표에 기록만 해두고, 추후 크레딧 화면을 만들 때 이 표를 그대로 옮겨 사용합니다.

---

## 6. 워크플로우 (에셋을 새로 추가할 때)

1. `사운드_큐_리스트.md` 또는 `아트스타일_가이드_MVP.md`를 참고해 어떤 에셋이 필요한지 확인
2. 2장의 추천 소스(또는 직접 제작)에서 에셋 확보
3. 라이선스 확인 후 4장의 표에 기록
4. `에셋_네이밍_관리규칙.md` 규칙에 맞게 파일명 변경 후 해당 폴더에 저장
5. 출처 표기가 필요한 에셋이면 추후 크레딧 화면에 포함될 수 있도록 별도 표시
