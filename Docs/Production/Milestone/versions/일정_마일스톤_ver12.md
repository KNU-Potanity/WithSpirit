## 6. 8월 주차별 역할 분담 (2026-08-04 추가)

5장의 주차별 목표를 역할별(프로그래밍/기획/아트)로 나눴습니다. 세부 항목은 `ToDoList.md` 4장에 있는 것을 그대로 가져온 것이며, 완료된 항목은 제외하고 남은 작업 위주로 정리했습니다.

### 6.1 8월 1주차 — 적 몬스터의 모든 구현

**프로그래밍**
- 아직 씬에 오브젝트가 없는 몬스터는 오브젝트/프리팹부터 생성하고, 기존에 구현된 몬스터(버섯/벌)와 동일한 패턴(Patrol/Chase/Attack 상태 머신 + Animator 연동)을 전부 적용
- ⚠️ (Critical) 공중 몬스터 사망 페이드 아웃 중 이동+공격 모두 계속되는 버그 수정 — 사망 후에도 실제 데미지가 들어감 (지상 몬스터는 이미 정상, `QA_테스트_계획서.md` BUG-01 참고)
- 빈 껍데기 상태인 `ProjectileTypes`/`DebuffTypes`/`PlatformTypes` enum 값 채우기
- 나머지 몬스터 5종(슬라임/나무골렘/식충식물/스켈레톤/밤나무) 데이터 에셋 생성 + 기존 2종 이름을 네이밍 규칙(`SO_Monster_이름`)에 맞게 정리
- `DebuffMonsterData`에 디버프 지속시간·감소율 필드 추가
- 보스 전용 `BossMonsterData` 클래스 신설 (근접+원거리 복합 패턴)
- `MonsterFacing.cs` 실제 필요 여부 검토 (이동 스크립트가 이미 자체 처리 중)

**기획**
- 보스(밤 나무) 패턴 설계
- `스탯_기획서.md` 3.6절 제안 초안값(나머지 5종)을 실제 확정값으로 검토·수정

**아트**
- 몬스터 애니메이션은 이미 확보되어 있으므로, 실제 인게임 확인 후 어색한 부분(크기/좌우 반전 등) 보정 위주

### 6.2 8월 2주차 — 플랫폼의 모든 구현

**프로그래밍**
