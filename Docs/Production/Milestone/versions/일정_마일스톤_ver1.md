# 일정 / 마일스톤 문서 — 핵심 기능 (혼자, 내일까지)

## 0. 문서 목적

이 문서는 혼자서 **내일까지** 핵심 기능 MVP를 완성하기 위한 시간 단위 일정입니다.

---

## 1. 작업 일정

전체 작업을 **시간 단위 블록**으로 나눴습니다. 실제 시작 시각에 맞춰 그대로 적용하면 됩니다. 총 작업량은 약 6~8시간 분량으로 추정했고, 중간에 휴식 시간은 포함하지 않았으니 적절히 끼워 넣으세요.

| 블록 | 예상 소요 | 작업 내용 | 완료 기준 |
|---|---|---|---|
| 1 | 30분 | Unity 프로젝트 세팅 (폴더 구조, GitHub 저장소 연결, Git 설정) | `기술기획서_MVP_Unity.md`의 폴더 구조대로 빈 프로젝트 생성 |
| 2 | 1.5시간 | 캐릭터 좌우 이동 + 기본 점프 구현 | `캐릭터컨트롤_스펙_MVP.md` 수치(속도, 가속/감속, 점프 높이) 적용, 평지에서 정상 동작 |
| 3 | 1시간 | 가변 점프 + 코요테 타임 구현 | 짧게 누르면 낮게, 길게 누르면 높게 점프 / 발판 벗어난 직후 짧게 점프 허용 |
| 4 | 1시간 | 지형/충돌 처리 (일반 발판 + 즉사 장애물) | 발판 위 이동 정상, 가시·낭떠러지 접촉 시 리스폰 트리거 발생 |
| 5 | 30분 | 리스폰 시스템 | 즉사 장애물 접촉 시 시작 지점으로 즉시 리스폰 |
| 6 | 30분 | 목표 지점 구현 | 도착 지점 접촉 시 클리어 판정 (디버그 로그나 임시 텍스트로 확인) |
| 7 | 1시간 | 카메라 추적 구현 | 플레이어 추적 + 스테이지 경계에서 멈춤 (Cinemachine 또는 간단한 추적 스크립트) |
| 8 | 1~1.5시간 | 레벨디자인 문서 기준 그레이박스 제작 (구간①~⑤) | `레벨디자인_MVP_스테이지1.md` 패턴대로 Tilemap 배치 |
| 9 | 1시간 | 전체 플레이 테스트 및 1차 수치 조정 | 시작~도착까지 끊기지 않고 플레이 가능 |

**우선순위 원칙**: 시간이 부족해지면 8~9번(레벨 디테일, 수치 튜닝)을 가장 먼저 줄이세요. 1~7번(핵심 기능 자체)이 동작하는 것이 "내일까지 완성"의 최소 기준입니다.

---

## 2. 완료 기준 (내일까지 달성해야 하는 최소 기준)

- [ ] 이동 + 점프 + 코요테 타임 동작
- [ ] 발판 충돌 정상 처리
- [ ] 즉사 장애물 접촉 시 리스폰
- [ ] 도착 지점 클리어 판정
- [ ] 카메라가 캐릭터를 따라 스크롤
- [ ] 시작부터 도착까지 끊기지 않고 1회 이상 플레이 가능

> 위 6개만 만족하면 "핵심 기능 MVP"는 완성된 것으로 간주합니다. 레벨이 5개 구간을 모두 갖추지 못해도, 발판+장애물+도착 지점이 최소 1세트라도 있으면 검증 목적은 달성됩니다.
