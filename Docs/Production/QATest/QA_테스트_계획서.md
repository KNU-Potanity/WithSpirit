## 6. 버그 우선순위 분류

| 우선순위 | 기준 | 예시 |

## 10. 발견된 버그 (2026-08-20 발견, 프로그래머 처리 필요)

### BUG-01. 여러 몬스터가 같이 타겟팅됨

- **증상**: 폭발 정령 구현 중 발견. 몬스터 여러 마리가 겹쳐있거나 인접한 상황에서, 마우스를 하나의 몬스터에 올려도 여러 마커가 동시에 활성화되거나 의도치 않은 몬스터가 타겟팅되는 것으로 보입니다.
- **재현 방법**: (부원이 아직 상세 재현 절차를 남기지 않음 — 몬스터 여러 마리가 인접한 상황에서 마우스를 올려보면서 확인 필요)
- **기대 동작**: 마우스와 겹치는 몬스터가 여러 마리여도, 가장 가까운 몬스터 단 하나만 마커가 뜨고 타겟팅되어야 함
- **관련 코드**: `MonsterClickMarker.cs`에 이미 "전역 단일 타겟팅"(`EvaluateCurrentTarget`, 매 프레임 마우스와 겹치는 모든 마커 중 가장 가까운 것 하나만 선택) 로직이 있는데, 이 로직으로 완전히 해결되지 않은 것으로 보임
- **상태**: 발견됨, 수정 예정 (담당 부원이 원인 분석 중) — **2026-08-20 부분 조치**: `MonsterHealth.Die()`에 사망한 몬스터의 `MonsterClickMarker`를 강제로 숨기고 비활성화하는 코드가 추가됨(죽은 몬스터의 마커가 타겟팅에 계속 끼어드는 경우를 막기 위한 것으로 추정). 다만 이게 이 버그의 근본 수정인지, 아니면 별개의 부수 정리인지는 재테스트로 확인 필요 — 아직 BUG-01을 해결됨으로 표시하지 않음.
- **우선순위**: Major

## 11. 문서-실제 구현 불일치 사항

설계 문서에 적힌 값·동작과 실제 게임에 구현된 것이 다른 부분을 모아둔 절입니다. 10장의 "버그"(의도와 무관하게 오동작하는 것)와 달리, 아래 항목들은 그 자체로는 정상 동작하지만 설계 문서의 확정값과 다르게 만들어진 것들입니다.

### 11.1 정령

| 항목 | 설계 | 실제 |
|---|---|---|
| 플랫폼 변신 해제 조건 | 공격 쿨타임이 지난 후 공격 키 입력 | 빈 공간 좌클릭이 해제 트리거 (쿨타임과 무관) |
| 폭발 정령 범위 | 3×3 범위 | 원형 범위(반경 2.5) |
| 화상 정령 색상 | 빨간색 | 주황색 (RGB 1, 0.45, 0.1) |
| 화상 지속시간 | 6초 (3회 틱) | `burnDuration` 기본값 0 (사망 시까지 무한 지속) |
| 빙결 정령 색상 | 파란색 | 하늘색 계열 (RGB 0.4, 0.8, 1) |
| 정령 6종 공격력/쿨타임 | 아래 11.2절 목표 수치 | 6종 데이터 에셋 모두 클래스 기본값(공격력 1 / 쿨타임 0.5) 그대로 |
| 플랫폼 특화 정령 쿨타임 | 1.0초 | 0.5초 (`PlatformSize`도 0으로 미입력) |

- 설계에 없던 동작: 정령 획득 카드 선택 UI가 열려있는 동안 게임이 일시정지됩니다(`Time.timeScale=0`).
- 기본 정령 애니메이션 연동 미완료: 공격 돌진/복귀 중 Animator의 Speed/Interact 파라미터가 세팅되지 않아 항상 Idle로 보입니다.
- 정령 획득 UI·트리거 배선이 `BossTest.unity`에만 되어 있고, 실제 플레이 씬(Stage1~3)에는 아직 적용되지 않았습니다.

> 관련 설계: `정령_시스템_기획서.md`
