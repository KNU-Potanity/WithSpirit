# 스탯 기획서

## 0. 문서 목적

확장 단계에서 등장하는 플레이어·정령·몬스터의 스탯 **항목 및 확정 수치**를 정리합니다. 아래 수치는 밸런스 기준값이며, 플레이 테스트(`QA_테스트_계획서.md` 9장 E-01~E-15) 결과에 따라 조정될 수 있습니다.

> 이 문서는 설계 확정값만 다룹니다. 실제 데이터 에셋 값과의 차이는 `QA_테스트_계획서.md` 11장에서 관리합니다.

---

## 1. 플레이어

| 스탯 | 설명 |
|---|---|
| 점프력 | `캐릭터컨트롤_스펙.md`의 점프 스펙과 연결 |
| 이동 속도 | `캐릭터컨트롤_스펙.md`의 이동 스펙과 연결 |
| 체력 | 하트 단위로 표시. 낙사를 제외한 데미지는 하트 1씩 감소 (`월드_스테이지_구성.md` 6장 참고) |

## 2. 정령

### 2.1 기본 정령

| 스탯 | 수치 |
|---|---|
| 공격력 | 1 |
| 쿨타임 | 0.5초 |
| 플랫폼 크기 | 2.0 × 0.3 유닛 (플레이어 1회 착지 가능한 폭) |
| 플랫폼 종류 | 버프 없는 일반 발판형 1종 (추가 정령의 플랫폼 특화 효과 없음) |

### 2.2 공격 특화 정령 (폭발/화상/빙결)

#### 폭발 정령 — 주황색

| 스탯 | 수치 |
|---|---|
| 공격력 | 1 |
| 쿨타임 | 1 |
| 범위 | 3 (공격한 몬스터 기준 3×3 범위 내 모든 적에게 데미지) |
| 상태이상 효과 부여 | 없음 |

> 설명: 공격한 몬스터를 기준으로 광역 피해를 입힙니다.

#### 화상 정령 — 빨간색

| 스탯 | 수치 |
|---|---|
| 공격력 | 0 |
| 쿨타임 | 1.5 |
| 범위 | 1 |
| 상태이상 효과 부여 | 화상 (상세 수치는 4.2절 참고) |

> 설명: 공격한 몬스터에게 2초마다 1데미지를 입히는 화상 효과를 부여합니다.

#### 빙결 정령 — 파란색

| 스탯 | 수치 |
|---|---|
| 공격력 | 0 |
| 쿨타임 | 1 |
| 범위 | 1 |
| 상태이상 효과 부여 | 빙결 (상세 수치는 4.3절 참고) |

> 설명: 공격한 몬스터에게 3초동안 이동 및 공격을 정지시키는 빙결 효과를 부여합니다.

### 2.3 플랫폼 특화 정령 (점프력강화/이속증가/장막제공)

공통: 쿨타임 1.0초 (플랫폼 재생성 대기시간), 발판 크기는 기본 정령과 동일(2.0 × 0.3 유닛). `발판_확장_기획서.md` 1.1절의 스탯 변화 발판 3종과 동일한 효과입니다.

#### 점프력 강화 정령 — 노란색

> 설명: 원래 점프 높이의 1.5배만큼 더 높이 뛰게 해주는 점프력 강화 발판을 설치합니다.

#### 이속 증가 정령 — 하늘색

> 설명: 밟고 난 후 3초 동안 이동 속도의 1.5배를 제공하는 이동 속도 증가 발판을 설치합니다.

#### 장막 제공 정령 — 초록색

> 설명: 데미지 1회를 막아주는 장막 제공 발판을 설치합니다.

## 3. 몬스터

### 3.1 공통

| 스탯 | 수치 |
|---|---|
| 체력 | 근거리형 10 / 원거리형 8 / 디버프형 6 / 보스 60 |
| 이동 속도 | 근거리형 2.0유닛/초 / 원거리형 1.0유닛/초(제자리 순찰 위주) / 디버프형 1.5유닛/초 / 보스 1.5유닛/초 |
| 공격력 | 하트 1 감소로 고정 (몬스터 종류와 무관하게 접촉·투사체 피격 시 동일 — `월드_스테이지_구성.md` 6장) |
| 쿨타임 | 공격 재사용 대기시간 1.5초 (공통 기준값, 보스는 3.5절 참고) |

### 3.2 디버프형 추가 스탯

| 스탯 | 수치 |
|---|---|
| 디버프 종류 | 슬라임 접촉 시 상태이상 "둔화" 부여 (상세 수치는 4.1절 참고) |
| 공격 범위 | 근접 접촉형, 판정 범위 0.5유닛 |

### 3.3 근거리형 추가 스탯

공통 스탯(3.1)만 사용합니다 (추가 스탯 없음).

### 3.4 원거리형 추가 스탯

| 스탯 | 수치 |
|---|---|
| 공격 범위 | 감지 범위 5.0유닛 / 발사 사거리 4.0유닛 |
| 투사체 종류 | 단일 직선 투사체 (스켈레톤: 화살) — 투사체 속도 8.0유닛/초 |
| 발사 방식 | 플레이어 위치를 조준해 직선으로 발사, 발사 후 쿨타임(3.1절 기준 1.5초) 동안 재장전 |

### 3.5 보스 추가 스탯

| 스탯 | 수치 |
|---|---|
| 공격 범위 | 근접 패턴 3.0유닛 / 원거리 패턴 사거리 6.0유닛 (패턴 전환형) |
| 투사체 종류 | 낙엽 폭풍(광역) / 뿌리 공격(근접 돌출형) — 세부 패턴 타이밍과 연출은 별도 보스 설계 문서에서 확정 (`몬스터_기획서.md` 4장 참고) |

## 4. 상태이상

몬스터/정령 관련 항목에서는 상태이상의 **이름만** 표기하고, 실제 수치는 이 절에 모아서 정리합니다.

### 4.1 둔화 (Slow)

| 항목 | 내용 |
|---|---|
| 적용 대상 | 플레이어 |
| 발생 조건 | 슬라임 접촉 시 |
| 효과 | 이동 속도 50% 감소 |
| 지속시간 | 3초 |
| 시각적 효과 | 적용 중 플레이어 색이 **하늘색**으로 변경 (지속시간 끝나면 원래 색으로 복귀) |

### 4.2 화상 (Burn)

| 항목 | 내용 |
|---|---|
| 적용 대상 | 몬스터 |
| 발생 조건 | 공격 특화 정령(화상형) 공격 명중 시 |
| 효과 | 2초마다 1데미지 (지속 데미지) |
| 지속시간 | 6초 (총 3회 틱) |
| 시각적 효과 | 적용 중 몬스터 색이 **빨간색**으로 변경 (지속시간 끝나면 원래 색으로 복귀) |

### 4.3 빙결 (Freeze, 기존 "스턴"을 대체)

| 항목 | 내용 |
|---|---|
| 적용 대상 | 몬스터 |
| 발생 조건 | 공격 특화 정령(빙결형) 공격 명중 시 |
| 효과 | 행동 불가 (이동/공격 정지) |
| 지속시간 | 3초 |
| 시각적 효과 | 적용 중 몬스터 색이 **파란색**으로 변경 (지속시간 끝나면 원래 색으로 복귀) |

> 4.2·4.3절의 색상·지속시간과 실제 구현 값의 차이는 `QA_테스트_계획서.md` 11.1절 참고.
