# 스탯 기획서

## 0. 문서 목적

확장 단계에서 등장하는 플레이어·정령·몬스터의 스탯 **항목 및 수치**를 정리합니다. 아래 수치는 1차 밸런스 기준값이며, 플레이 테스트(`QA_테스트_계획서.md` 9장 E-01~E-15) 결과에 따라 조정될 수 있습니다.

## 1. 플레이어

| 스탯 | 설명 |
|---|---|
| 점프력 | `캐릭터컨트롤_스펙.md`의 점프 스펙과 연결 |

## 2. 정령

### 2.1 기본 정령

| 스탯 | 수치 |
|---|---|
| 공격력 | 1 (실제 에셋 `MainFairyData.asset` 값으로 수정) |
| 쿨타임 | 0.5초 (실제 에셋 `MainFairyData.asset` 값 기준으로 수정) |
| 플랫폼 크기 | 2.0 × 0.3 유닛 (플레이어 1회 착지 가능한 폭) |
| 플랫폼 종류 | 버프 없는 일반 발판형 1종 (추가 정령의 플랫폼 특화 효과 없음) |

### 2.2 공격 특화 정령 (목표 수치 확정: 폭발/화상/빙결) — ⚠️ 실제 에셋 값 미반영

> 아래는 **설계 목표 수치**입니다. 실제 `ExplosionFairyData`/`BurnFairyData`/`FreezeFairyData` 에셋은 3종 모두 여전히 클래스 기본값(**공격력 1, 쿨타임 0.5, 범위 미구현**) 그대로이며, 정령별 개별 수치는 아직 코드/에셋에 반영되지 않았습니다. `범위`(3×3 등)에 대응하는 필드 자체가 현재 데이터 구조에 없습니다.

#### 폭발 정령 — 주황색

| 스탯 | 목표 수치 | 실제 에셋 값 |
|---|---|---|
| 공격력 | 1 | 1 (일치) |
| 쿨타임 | 1 | 0.5 (불일치) |
| 범위 | 3 (공격한 몬스터 기준 3×3 범위 내 모든 적에게 데미지) | 필드 없음 — 실제 코드는 반경 2.5의 원형 범위로 구현 (`정령_시스템_기획서.md` 3.8절) |
| 상태이상 효과 부여 | 없음 | 없음 (일치) |

> 설명: 공격한 몬스터를 기준으로 광역 피해를 입힙니다.

#### 화상 정령 — 빨간색

| 스탯 | 목표 수치 | 실제 에셋 값 |
|---|---|---|
| 공격력 | 0 | 1 (불일치) |
| 쿨타임 | 1.5 | 0.5 (불일치) |
| 범위 | 1 | 필드 없음 |
| 상태이상 효과 부여 | 화상 (상세 수치는 4.2절 참고) | 화상 적용은 구현됨, 지속시간 등은 4.2절 참고 |

> 설명: 공격한 몬스터에게 2초마다 1데미지를 입히는 화상 효과를 부여합니다.

#### 빙결 정령 — 파란색

| 스탯 | 목표 수치 | 실제 에셋 값 |
|---|---|---|
| 공격력 | 0 | 1 (불일치) |
| 쿨타임 | 1 | 0.5 (불일치) |
| 범위 | 1 | 필드 없음 |
| 상태이상 효과 부여 | 빙결 (상세 수치는 4.3절 참고) | 빙결 적용은 구현됨, 지속시간 등은 4.3절 참고 |

> 설명: 공격한 몬스터에게 3초동안 이동 및 공격을 정지시키는 빙결 효과를 부여합니다.

### 2.3 플랫폼 특화 정령 (개별 정리: 점프력강화/이속증가/장막제공) — ⚠️ 실제 에셋 값 미반영

공통 목표: 쿨타임 1.0초 (플랫폼 재생성 대기시간), 발판 크기는 기본 정령과 동일(2.0 × 0.3 유닛). `발판_확장_기획서.md` 1.1절의 스탯 변화 발판 3종과 동일한 효과입니다.

> 실제 `JumpBoostFairyData`/`SpeedBoostFairyData`/`BarrierFairyData` 에셋은 3종 모두 `CoolTime=0.5`(목표 1.0과 불일치), `PlatformSize=0`(발판 크기 필드가 아직 값이 채워지지 않음) 상태입니다. 각 정령이 만드는 플랫폼 프리팹(`JumpBoostPlatform`/`SpeedBoostPlatform`/`BarrierPlatform`) 연결 자체는 정확히 되어 있습니다 (`정령_시스템_기획서.md` 7.8절 참고).

#### 점프력 강화 정령 — 노란색

> 설명: 원래 점프 높이의 1.5배만큼 더 높이 뛰게 해주는 점프력 강화 발판을 설치합니다.

#### 이속 증가 정령 — 하늘색

> 설명: 밟고 난 후 3초 동안 이동 속도의 1.5배를 제공하는 이동 속도 증가 발판을 설치합니다.

#### 장막 제공 정령 — 초록색

> 설명: 데미지 1회를 막아주는 장막 제공 발판을 설치합니다.

| 스탯 | 수치 |
|---|---|
| 공격 범위 | 근접 패턴 3.0유닛 / 원거리 패턴 사거리 6.0유닛 (패턴 전환형) |
| 투사체 종류 | 낙엽 폭풍(광역) / 뿌리 공격(근접 돌출형) — 세부 패턴 타이밍과 연출은 별도 보스 설계 문서에서 확정 (`몬스터_기획서.md` 4장 참고) |

### 3.6 몬스터별 개별 수치 (ScriptableObject 필드 기준 추가)

3.1~3.5절의 분류별 수치는 설계 방향이고, 실제 구현은 `MonsterData`(공통) + `GroundMonsterData`/`FloatingMonsterData`/`RangedMonsterData`/`DebuffMonsterData`(유형별) 필드 구조를 따릅니다. 이 절은 **몬스터 이름 하나하나에 대한 실제 데이터 에셋 수치**를 정리합니다 (`스크립트_설명서.md`의 ScriptableObject 구조 참고).

| 상태 표시 | 의미 |
|---|---|
| ✅ 구현 완료 | 실제 데이터 에셋(.asset)이 존재하고 Inspector에서 확인한 값 |
| 📝 제안 초안 | 아직 데이터 에셋이 없어, 3.1~3.5절 방향과 벌/버섯의 실측값을 참고해 제안하는 값 (담당자가 에셋 생성 시 조정 가능) |

## 4. 상태이상 (추가 갱신)

몬스터/정령 관련 항목에서는 상태이상의 **이름만** 표기하고, 실제 수치는 이 절에 모아서 정리합니다.

### 4.1 둔화 (Slow)

| 항목 | 내용 |
|---|---|
| 적용 대상 | 플레이어 |
| 발생 조건 | 슬라임 접촉 시 |
| 효과 | 이동 속도 50% 감소 |
| 지속시간 | 3초 |
| 시각적 효과 | 적용 중 플레이어 색이 **하늘색**으로 변경 (지속시간 끝나면 원래 색으로 복귀) |
| 참고 | ✅ `DebuffMonsterData`에 `Duration`/`SpeedDecreaseRate` 필드가 추가되어 구현 완료됨 |

### 4.2 화상 (Burn) — 신규

| 항목 | 내용 |
|---|---|
| 적용 대상 | 몬스터 |
| 발생 조건 | 공격 특화 정령(화상형) 공격 명중 시 |
| 효과 | 2초마다 1데미지 (지속 데미지) |
| 지속시간 | 6초 (총 3회 틱) |
| 시각적 효과 | 적용 중 몬스터 색이 **빨간색**으로 변경 (지속시간 끝나면 원래 색으로 복귀) — ⚠️ 실제 `MonsterBurnEffect.cs` 기본값은 **주황색**(RGB 1, 0.45, 0.1)으로 구현되어 있어 다름 |
| 참고 | ⚠️ `burnDuration` 기본값이 0(=사망 시까지 무한 지속)으로 되어 있어, 6초 제한이 실제로 걸려있지 않음 (확인, `정령_시스템_기획서.md` 3.8절 참고) |

### 4.3 빙결 (Freeze) — 신규 (기존 "스턴"을 대체)

| 항목 | 내용 |
|---|---|
| 적용 대상 | 몬스터 |
| 발생 조건 | 공격 특화 정령(빙결형) 공격 명중 시 |
| 효과 | 행동 불가 (이동/공격 정지) |
| 지속시간 | 3초 |
| 시각적 효과 | 적용 중 몬스터 색이 **파란색**으로 변경 (지속시간 끝나면 원래 색으로 복귀) — ⚠️ 실제 `MonsterFreezeEffect.cs` 기본값은 **하늘색에 가까운 색**(RGB 0.4, 0.8, 1)으로 구현되어 있어 다소 다름 |
