# 월드/스테이지 구성 기획서

## 0. 문서 목적

> 마지막 수정일: 2026-07-16 (6.1절에 하트 UI 2-레이어 구현 방식 추가 — ver4)

확장 단계의 테마(월드)별 스테이지 구성, 정령 등장 진행, 스토리 개요, 클리어·게임오버 조건을 정리합니다.

---

## 1. 테마(월드) 구성

| 테마 | 배경 | 스테이지 수 | 정령 등장 |
|---|---|---|---|
| 테마 1 | 마을 또는 도시 | 1 스테이지 (약 5분 분량, 튜토리얼 격) | 기본 정령만 등장 |
| 테마 2 | 변방 | 2 스테이지 | 추가 정령 1~2개 등장 |
| 테마 3 | 숲 | 2 스테이지 | 추가 정령 최대 개수(3개)까지 등장 |

> 기본 테마는 총 3개입니다.

### 1.1 테마 1 상세 (튜토리얼)

1 스테이지를 두 파트로 구성합니다.

| 파트 | 내용 |
|---|---|
| 앞 파트 | 정령 없이 진행. 조작키(이동·점프) 튜토리얼. 중간에 플레이어 혼자서는 통과할 수 없는 구간이 등장 |
| 전환 | 위 구간에서 정령이 등장해 문제를 해결 → 후반부로 진입 |
| 뒤 파트 | 정령 사용법(마커, 클릭 상호작용) 튜토리얼 |

---

## 2. 스토리

스토리 구체화 작업이 완료되어, 상세 내용은 별도 문서로 분리했습니다.

- **상세 내용**: `Docs/Design/Story/스토리.md` 참고 (로그라인, 테마별 스토리 비트, 정령·보스의 서사적 의미, 엔딩 개요 포함)
- 정령을 동료(자아)로 설정한 세계관(`정령_시스템_기획서.md` 4장)과 맞물리도록 작성되었습니다.

---

## 3. 스테이지 구성 요소

스테이지는 아래 요소들로 구성됩니다.

- 플랫폼 (일반·이동·무너짐·스탯변화 — `발판_확장_기획서.md`)
- 장애물 (가시, 낙사 등 기존 MVP 요소)
- 뒷배경
- 장식
- 몬스터 (`몬스터_기획서.md`)
- 설치 장소 (정령이 플랫폼을 생성할 수 있는 지점)

---

## 4. 카메라

확장 단계에서도 카메라 로직은 수정하지 않습니다. 기존 추적 카메라(`기술기획서.md` 4.5절)를 그대로 사용합니다.

## 5. 게임 클리어 기준

| 단위 | 조건 |
|---|---|
| 스테이지 | 각 스테이지의 도착 지점에 도달하면 클리어 |
| 게임 전체 | 최종 스테이지(테마 3)에서 보스(밤 나무) 처치 |

---

## 6. 리스폰 / 생명

- 리스폰 방식은 MVP와 동일하게 즉시 시작 지점으로 복귀합니다 (체크포인트 없음).
- 플레이어 체력은 하트 아이콘으로 표시되며, 최대 개수는 **4개**입니다.
  - 낙사: 체력이 즉시 0으로 감소 (하트 전부 소진 → 8장 게임 오버 조건 트리거)
  - 낙사를 제외한 데미지(몬스터 접촉, 원거리 공격, 가시 등): 하트 1씩 감소
  - 하트가 모두 소진되면 게임 오버 (8장 참고)

### 6.1 하트 UI

| 항목 | 내용 |
|---|---|
| 최대 개수 | 4개 |
| 위치 | 화면 좌측 상단 |
| 배치 방식 | 왼쪽부터 오른쪽으로 4개를 가로로 나열, 현재 체력만큼 채워진 하트로, 나머지는 빈 하트로 표시 |
| 채워진 하트 (체력 있음) | 빨간색 채우기 + 검정색 외곽선 |
| 빈 하트 (체력 없음) | 검정색 단색 (채우기 없이 검정 아이콘) |

**구현 방식 (2026-07-16 확정)**: 원본 하트 아이콘(`heart.png`, 검정 실루엣)은 `SpriteRenderer.color`가 곱셈(multiply) 방식으로 틴트되기 때문에 검정 픽셀에는 색이 먹지 않는 문제가 있어, 아래처럼 2개의 스프라이트 레이어로 분리해 구현합니다.

| 레이어 | 에셋 | 역할 |
|---|---|---|
| 외곽선 (뒤) | `Assets/UI/Icons/Heart/heart.png` | 검정 실루엣, 고정(색 변경 없음) |
| 채우기 (앞) | `Assets/UI/Icons/Heart/heart_fill.png` | 원본을 안쪽으로 침식(erode)시켜 흰색으로 채운 파생 이미지. `color`로 빨강(체력 있음)/검정(체력 없음)을 토글 |

- `heart_fill.png`는 `heart.png`(Flaticon, meaicon 제작)의 파생물이므로 동일한 출처 표기 의무를 따릅니다 — `에셋_출처_라이선스_관리.md` 4장·6장 참고.

## 7. 게임 오버 요소 (데미지·사망 원인)

| 요소 | 설명 |
|---|---|
| 가시 | 기존 MVP 즉사 장애물 |
| 낙사 | 체력이 즉시 0으로 감소 (하트 전부 소진, 게임 오버 트리거) — 즉시 리스폰 없이 8장 게임 오버 조건으로 처리 |
| 원거리 공격 | 몬스터의 투사체 등에 맞음 |
| 접촉 데미지 | 몬스터에 직접 닿음 |
| 디버프 | 슬라임 등 디버프형 몬스터 접촉 |
