### 1.5 실제 구현 현황 — 데모 스테이지 1 완성 (2026-08-27 추가)

`Stage1.unity`이 처음부터 끝까지 플레이 가능한 **데모 스테이지**로 완성됐습니다. 3.1절 배치 순서의 나머지 단계(상호작용 → 몬스터 → 장식)까지 채워진 첫 스테이지입니다.

| 그룹 | 배치 내용 |
|---|---|
| Interactables | 정령 플랫폼 설치 장소(`PlatformPlace`) 1개 |
| Hazards | `Thorn` 프리팹 12개 — **개별 프리팹 배치 방식** (Stage2·3에 만들어둔 `HazardTilemap` 방식과 다름, 5.x절 참고) |
| Monsters | 버섯(`Mushroom`) 1마리 |
| Boss | 미배치 (테마 1은 보스 없음, `몬스터_기획서.md` 3장과 일치) |
| Decoration | 미배치 |

**정령 시스템도 함께 배치됨**: `Fairy`(기본 정령), `FairyManager`, `MousePointer`(커스텀 커서)가 씬에 추가되어, 기본 정령을 데리고 다니며 몬스터 공격·플랫폼 설치까지 실제로 플레이할 수 있는 상태입니다. 다만 **정령 획득 UI(`FairySelectUI`/`FairySelectTrigger`, 7장)는 아직 Stage1에 배치되지 않았습니다** — 기본 정령 하나로만 플레이하는 데모입니다.

⚠️ **가시 배치 방식이 스테이지마다 다릅니다**: Stage1은 `Thorn.prefab`을 낱개로 배치한 반면, Stage2·3은 `HazardTilemap`(전용 Tilemap 레이어) 방식을 씁니다. 관리 방식이 스테이지마다 갈리는 상태라, 추후 하나로 통일할지 결정이 필요합니다.

⚠️ **2026-08-27 확인 및 수정**: 이번 확인 과정에서 Stage1의 Ground 타일이 63칸으로 늘어나 있었는데, `CameraBounds`(X: -0.5~60.5)와 `PlayerMovement`의 이동 경계(X: 0~60)가 예전 크기(60) 그대로 남아있어서 **맨 끝 구간에서 카메라·플레이어가 막히는 문제**가 있었습니다. Stage2·3에서 발견했던 것과 같은 종류의 버그입니다. 지형 크기(X: -1~62)에 맞춰 `CameraBounds`(X: -2~63)와 이동 경계(X: -2~63)를 다시 계산해 수정했습니다.

### 6.1 하트 UI

| 항목 | 내용 |
|---|---|
| 최대 개수 | 4개 |
| 위치 | 화면 좌측 상단 |
| 배치 방식 | 왼쪽부터 오른쪽으로 4개를 가로로 나열, 현재 체력만큼 채워진 하트로, 나머지는 빈 하트로 표시 |
| 채워진 하트 (체력 있음) | 빨간색 채우기 + 검정색 외곽선 |
| 빈 하트 (체력 없음) | 검정색 단색 (채우기 없이 검정 아이콘) |

**구현 방식 (2026-07-16, 실제 코드 기준으로 수정)**: `HeartUI.cs`는 색 틴트가 아니라 **하트 개당 스프라이트를 통째로 교체하는 방식**으로 구현되어 있습니다. 현재 체력보다 인덱스가 작은 하트는 `fullHeartSprite`로, 그 이상은 `emptyHeartSprite`로 교체합니다.

| 스프라이트 필드 | 실제 연결된 에셋 (2026-07-21 확인) | 비고 |
|---|---|---|
| `fullHeartSprite` | `Assets/_Project/Art/UI/ui_heart_full.png` | Unity 자체 기능으로 직접 만든 **임시 플레이스홀더**. 곧 정식 아트로 교체 예정 |
| `emptyHeartSprite` | `Assets/_Project/Art/UI/ui_heart_empty.png` | 위와 동일하게 임시 플레이스홀더 |

- 이전에 검토했던 "외곽선(`heart.png`) + 채우기(`heart_fill.png`) 2-레이어를 `color`로 틴트"하는 방식과, 그 이후의 "Flaticon 기반 완성 이미지 하나 제작" 방향 모두 **실제로는 채택되지 않았습니다.** 지금은 Unity 자체 기능으로 만든 임시 스프라이트 2장이 연결되어 있으며, 정식 아트가 나오면 교체될 예정입니다.
- 제작 시 참고했던 `Assets/UI/Icons/Heart/heart.png`, `heart_fill.png`(Flaticon 기반)는 현재 **어디에도 연결되어 있지 않은 미사용 파일**입니다. 정식 아트 제작 시 참고용으로만 남겨두거나 정리가 필요합니다.
- 정식 아트로 교체될 때까지는 출처 표기 의무가 없습니다 (임시 플레이스홀더는 Unity 자체 기능으로 직접 제작). 다만 최종적으로 Flaticon 기반 이미지를 쓰기로 결정되면 그때 다시 `에셋_출처_라이선스_관리.md`에 표기해야 합니다.
