# 2D 플랫포머 게임 기획서 (MVP / 핵심 기능)

> 최근 갱신: — 확장 단계(정령 시스템) 설계가 채택되면서 1장의 비목표 항목을 갱신했습니다. 이 문서 본문(2~4장)은 MVP 단계에서 완료된 내용을 그대로 기록하며, 확장 단계의 구체적인 설계는 5장에 안내된 문서들을 참고하세요.

## 0. 문서 목적

이 문서는 **2D 플랫포머 장르에 공통적으로 들어가는 핵심 기능만 최소한으로 구현** 하는 것을 목표로 작성되었습니다.

- 이 문서에는 반드시 구현해야 하는 핵심(Core) 기능만 서술합니다.
- 추후 추가할 확장 기능 목록 및 설계 시 고려사항은 별도 문서(`플랫포머_게임_기획서_확장기능.md`)에 정리되어 있습니다.
- 핵심 기능을 설계할 때도, 확장 기능이 나중에 자연스럽게 붙을 수 있도록 시스템을 독립적으로 분리합니다. (자세한 원칙은 확장 기능 문서 참고)

## 2. 핵심 기능 정의

아래 5가지를 **반드시 구현해야 하는 핵심(Core)** 으로 정의합니다.

### 2.1 이동 (Movement)
- 좌우 이동 (가속/감속 적용)
- 기본 점프 (고정 높이, 단순한 포물선 운동)
- 코요테 타임 (발판을 벗어난 직후 짧게 점프 허용 — 정확한 시간은 `캐릭터컨트롤_스펙.md` 참고) — 플랫포머 특유의 '조작감'을 위해 핵심으로 포함

### 2.2 충돌 및 지형
- 일반 발판 (고정된 지형, 충돌 처리)
- 즉사 장애물 (가시, 낭떠러지 등 접촉 시 리스폰)

### 2.3 리스폰 / 생명 (최소 형태)
- 체크포인트 없이, **스테이지 시작 지점으로 즉시 리스폰**하는 가장 단순한 구조로 시작
- 생명 개수 제한 없음 (죽으면 바로 재시작, 게임오버 없음)
- (확장 단계) 플레이어 체력(하트)과 게임오버 조건이 추가되었습니다 — `월드_스테이지_구성.md` 6~8장 참고

### 2.4 목표 지점
- 스테이지 끝에 도달하면 클리어 처리되는 단순한 '도착 지점' 오브젝트 1종
- (확장 단계) 각 스테이지는 도착 지점 도달로 클리어하고, 최종 스테이지는 보스 처치가 클리어 조건입니다 — `월드_스테이지_구성.md` 5장 참고

### 2.5 카메라
- **플레이어 추적형 카메라**로 고정 (캐릭터 위치를 기준으로 따라가는 방식)
- 스테이지가 화면 1개 크기를 넘어가므로, 캐릭터를 따라가는 단순한 추적 카메라 필요
- 좌우 스크롤만 지원 (수직 스크롤, 줌, 화면 전환 효과 등은 제외)
- 화면 경계(스테이지 시작/끝)에서는 카메라 이동을 멈추는 정도의 단순 규칙만 적용
- (확장 단계) 카메라 로직은 수정하지 않습니다 — `월드_스테이지_구성.md` 4장 참고

## 3. 레벨 디자인 (MVP 범위)

- 스테이지 1개로 핵심 조작감을 검증 (여러 스테이지 구성은 MVP 이후로 미룸)
- 해당 스테이지는 다음 요소만으로 구성:
 - 일반 발판
 - 즉사 장애물 (최소 1종, 예: 낭떠러지 또는 가시)
 - 도착 지점 1개
- 난이도는 발판 간 거리와 장애물 배치만으로 조절 (적이나 추가 기믹 없이)

> 확장 단계의 다중 테마·다중 스테이지 구성은 `월드_스테이지_구성.md`에서 별도로 정의합니다.
