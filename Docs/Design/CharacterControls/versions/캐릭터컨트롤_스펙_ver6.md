# 캐릭터 컨트롤 스펙 문서 — MVP

## 0. 문서 목적 및 갱신 이력

이 문서는 `플랫포머_게임_기획서.md`에서 정의된 이동·점프 기능의 **확정 수치**를 기록합니다.

| 버전 | 날짜 | 변경 내용 |
|---|---|---|
| ver1 | 최초 작성 | 1차 추정치(초안) — 프로토타입 제작 전 추정값 |
| ver2 | 2026-06-30 | **확정본** — T-01~T-09 통과 후 실제 코드에 반영된 값으로 갱신. 구현 중 확정된 항목(접지 판정, 이동 경계, 즉사/목표 콜라이더) 추가 |
| ver5 | 2026-07-09 | 확장 단계 조작키(공격·정령 선택 마우스 클릭) 추가. 이동/점프 수치 자체는 변경 없음 |
| ver6 | 2026-07-14 | 피격 시 무적 시간 및 알파 깜빡임 연출 수치 추가 |

> ver1의 1차 추정치와 달리, 이 버전은 플레이 테스트(T-01~T-09) 완료 후 수치 조정 없이 그대로 확정된 것을 명시합니다.

## 1. 기준 단위

| 항목 | 값 | 비고 |
|---|---|---|
| 프레임레이트 | 60 FPS | 모든 시간 수치의 기준 |
| 1 타일 | 1 Unity Unit | Tilemap Grid cellSize=1 고정 (PPU=16 재임포트로 맞춤) |
| 캐릭터 히트박스 | 가로 0.8 × 세로 1.5 유닛 | 발판/장애물보다 살짝 작게, 시각적 여유 확보 |

> ver1에서 1타일 = 64px로 표기했으나, 실제 Unity 구현에서 Tilemap Grid cellSize=1(Unity Unit)로 통일했습니다. PPU=16 재임포트를 통해 스프라이트 1타일이 정확히 1 Unity Unit으로 맞춰졌습니다.

## 2. 이동 (좌우 이동) 스펙 — 확정

| 항목 | 확정값 | 스크립트 필드 |
|---|---|---|
| 최고 이동 속도 | 6.0 유닛/초 | `PlayerMovement.maxMoveSpeed` |
| 최고 속도까지 가속 시간 | 0.15초 | `PlayerMovement.accelerationTime` |
| 정지까지 감속 시간 | 0.10초 | `PlayerMovement.decelerationTime` |
| 방향 전환 시 감속/재가속 | 정지와 동일한 감속 후 재가속 | — |
| 이동 경계 (왼쪽) | x = 0 (스테이지 시작점) | `PlayerMovement.leftBoundX` |
| 이동 경계 (오른쪽) | x = 60 (마지막 타일 중심 기준) | `PlayerMovement.rightBoundX` |

## 8. 조작키 (확장 단계 추가, ver5)

이동·점프 수치는 위 2~3장 기준 그대로 유지되며, 확장 단계에서 아래 조작이 추가됩니다. 정령 시스템 전체 설명은 `정령_시스템_기획서.md`를 참고하세요.

| 동작 | 입력 |
|---|---|
| 이동 | A / D |
| 점프 | W / Space |
| 공격, 기본적인 상호작용 | 마우스 왼쪽 클릭 |
| 정령 선택 | 마우스 오른쪽 클릭 |

> 마우스 포인터를 상호작용 가능한 대상에 가져다 대면 마커가 표시되고, 그 상태에서 왼쪽 클릭하면 상호작용이 실행됩니다 (`정령_시스템_기획서.md` 2장 참고).

## 9. 피격 무적 시간 및 연출 — 신규 (ver6 추가)

| 항목 | 확정값 | 비고 |
|---|---|---|
| 무적 시간 | 0.5초 | 피격(하트 감소) 시점부터 시작, 이 시간 동안 추가 피격 무시 |
| 알파 깜빡임 주기 | 0.1초 | 무적 시간 동안 이 주기로 알파값을 번갈아 전환 |
| 알파 최솟값 | 0.2 | 깜빡임 시 캐릭터가 흐려지는 상태 |
| 알파 최댓값 | 1.0 | 깜빡임 시 캐릭터가 원래대로 보이는 상태 |
| 동작 방식 | 0.1초마다 알파 1.0 → 0.2 → 1.0 → 0.2 ... 반복 (0.5초 동안 총 5회 전환) | 무적 시간이 끝나면 알파는 1.0으로 고정 |
