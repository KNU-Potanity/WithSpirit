# 레벨 디자인 문서 — MVP 스테이지 1

> 📎 MVP(핵심 기능) 단계 문서 — 회장(PM)이 혼자 구현한 기존 기능 정의입니다. 새 기능 설계 시 기존 기준으로 참고하세요.


## 0. 문서 목적

이 문서는 `플랫포머_게임_기획서_MVP.md`에서 정의한 핵심 기능(이동, 충돌/지형, 리스폰, 목표 지점, 카메라)만으로 구성된 **단일 스테이지의 구체적인 레이아웃**을 정리합니다.

- 적, 파워업, 수집 아이템 없이 **발판 + 즉사 장애물 + 도착 지점**만으로 난이도 곡선을 만드는 것이 목표입니다.
- **ver5 변경 사항**: 스테이지 개요 표에 Tilemap 구조 및 깊이 정보(총 11단, 중간 타일/바닥 타일 구분) 추가.
- **ver4 변경 사항**: 1타일 단위 정의를 실제 구현 방식(PPU=16 복제본)으로 수정했고, 구간 범위 표기 오류(48~54가 ④/⑤로 표기됐던 것을 ④로 정정)와 구간⑤ 시작 좌표를 실제 값(55)으로 수정했습니다.
- **ver3 변경 사항**: Unity에 실제로 그레이박스를 구성하는 과정에서 좌표가 일부 조정되었습니다. 1칸짜리 단독 발판(28번 칸)이 시각적으로 옆 칸들과 이질감이 있어 29번 칸까지 발판을 넓혔고, 그로 인해 사라진 난이도를 보전하기 위해 29번 칸에도 가시를 추가했습니다. 아래 좌표는 ver2의 '1차 추정치'가 아니라 **실제로 구현된 좌표**입니다.

## 1. 스테이지 개요

| 항목 | 내용 |
|---|---|
| 총 길이 | 약 60 타일 (1타일 = Unity 1 유닛. 원본 타일은 16px 크기이며, `Assets/_Project/Tiles/Sources/`에 복제 후 PPU=16으로 재설정하여 1타일이 정확히 1유닛으로 렌더링됨 (`기술기획서_ver6.md` 4.2절 참고)) |
| 화면에 보이는 폭 | 약 12~14 타일 (카메라가 좌우로 스크롤하며 따라감) |
| 구성 | 5개 구간으로 진행 (난이도 점진적 상승) |
| 사용 요소 | 일반 발판, 갭(낭떠러지), 가시(즉사 장애물), 도착 지점 |
| Tilemap 구조 | `Grid` cellSize=(1,1,1), position=(-0.5,-1.0,0) / 타일(col,0)의 발판 표면 y=0 |
| Tilemap 깊이 | row 0(표면) ~ row -10(바닥), 총 11단. row 0~-9: 중간 타일(테두리 없음), row -10: 바닥 타일 |
| 미사용 요소 | 적, 이동 발판, 파워업, 수집 아이템 (모두 확장 기능 문서로 분리) |

## 2. 구간별 설계 의도

| 구간 | 범위(타일) | 목적 | 사용 요소 |
|---|---|---|---|
| ① 적응 구간 | 0~13 | 이동/점프 조작에 익숙해지는 구간, 위험 요소 없음 | 평지 발판만 |
| ② 기본 점프 구간 | 14~22 | 좁은 갭을 점프로 건너는 패턴 학습 | 1~2타일 갭 |
| ③ 정밀 점프 구간 | 23~35 | 가시를 피하며 발판 간 점프, 코요테 타임 체감 구간 | 갭 1칸 + 가시 연속 2칸(28,29) |
| ④ 응용 구간 | 36~50 | ②③에서 배운 패턴을 조합, 약간 더 넓은 갭 | 갭 + 가시 연속 배치 |
| ⑤ 마무리 구간 | 55~60 | 가장 큰 갭(4칸)으로 클라이맥스, 이후 도착 지점 | 큰 갭(55~58, 4칸) + 도착 발판(59~60) + 도착 지점 |

> 설계 원칙: 새로운 위험 요소(갭, 가시)는 **항상 안전한 구간 뒤에 단독으로 먼저 등장**시키고, 이후 구간에서 조합해서 난이도를 올립니다. 처음부터 조합된 형태로 등장하지 않도록 합니다.

## 3. 타일 레이아웃 (실제 구현 좌표)

아래는 Unity에 실제로 배치된 좌표를 기준으로 한 정확한 레이아웃입니다.
`=` 발판, (빈칸) 갭/허공, `^` 가시, `S` 시작 지점, `G` 도착 지점 입니다.

```
구간①(적응, 0~13)
S=============

구간②(기본 점프, 14~22)
 _===_===__==__   (14갭, 15-17발판, 18갭, 19-20발판, 21-22갭 2칸)

구간③(정밀 점프, 23~35)
====^_======_     (23-26발판·25에가시, 27갭, 28-33발판·28&29에가시, 34-35갭)

구간④(응용, 36~50)
===^_==_===_==_===  (36-38발판·38가시,39갭,40-41발판·41가시,42-43갭,44-46발판·46가시,47갭,48-50발판)

구간⑤(마무리, 51~60)
====____====G    (51-54발판, 55-58갭 4칸, 59-60발판+G)
```

> 위 다이어그램은 칸 수 비율을 맞추기 어려워 일부 생략 기호(`_`)로 단순화했습니다. 정확한 칸 번호는 아래 표를 참고하세요.

### 발판 구간 (시작~끝, 가시 위치)

| 구간 | 발판 범위 | 가시 위치 | 직전 갭 크기 |
|---|---|---|---|
| ① | 0~13 | 없음 | (시작 지점) |
| ② | 15~17 | 없음 | 14 (1칸) |
| ② | 19~20 | 없음 | 18 (1칸) |
| ③ | 23~26 | 25 | 21~22 (2칸) |
| ③ | 28~33 | 28, 29 | 27 (1칸) |
| ④ | 36~38 | 38 | 34~35 (2칸) |
| ④ | 40~41 | 41 | 39 (1칸) |
| ④ | 44~46 | 46 | 42~43 (2칸) |
| ④ | 48~54 | 없음 | 47 (1칸) |
| ⑤ | 59~60 (G) | 없음 | 55~58 (4칸, 최대 난이도) |

### 구간별 상세 패턴

- **구간①**: 갭/가시 없이 14타일 평지(0~13). 좌우 이동과 기본 점프만 자연스럽게 유도.
- **구간②**: 1타일 갭 2회(14, 18) → 2타일 갭 1회(21~22) 순서로 점진적 확대. 실패해도 바로 리스폰되는 가벼운 학습 구간.
- **구간③**: 23~26 발판 위 25번에 가시 1개 단독 배치(밟지 않고 넘어가야 함) → 27번 갭과 28~33 발판이 이어지지만, **28번과 29번 두 칸 모두 가시가 있어 실질적으로 안전하게 착지할 수 없음**. 따라서 26번에서 도약해 갭(27)과 가시 2칸(28, 29)을 한 번에 넘어 30번에 착지해야 하는 4칸 점프가 이 구간의 핵심 도전 구간입니다. 코요테 타임이 체감되는 구간(발판 끝에서 살짝 늦게 점프해도 성공하는 경험을 의도적으로 배치).
- **구간④**: 갭과 가시가 연속으로 3회 조합되어 등장(38, 41, 46 각각 가시 직후 안전 발판). 실패 시 리스폰 지점은 구간 시작점으로 즉시 복귀(체크포인트 없음 — MVP 사양).
- **구간⑤**: 55~58(4칸)로 스테이지에서 가장 넓은 갭을 만들고, 성공 시 바로 도착 지점(60, G)에 도달. `캐릭터컨트롤_스펙_MVP.md`의 최대 점프 거리(4.5~5타일) 기준에 맞춰 캡을 적용한 수치입니다.

## 4. 난이도 곡선 (체감 기준)

```
난이도
  ↑                                   ●(⑤ 클라이맥스)
  |                            ●(④)
  |                    ●(③)
  |            ●(②)
  |  ●(①)
  └─────────────────────────────────────→ 진행도
```

- 급격한 난이도 점프 없이, 한 구간에서 1가지 새로운 패턴만 추가되도록 설계했어요.
- ⑤구간만 의도적으로 체감 난이도를 한 번 더 올려서 "클리어했다"는 성취감을 주는 구조예요.

---

## 5. 카메라 동작 확인 포인트

- 스테이지 총 길이(60타일)가 화면 폭(약 12~14타일)보다 훨씬 길기 때문에, MVP 기획서에 정의된 **플레이어 추적형 카메라**가 정상적으로 좌우 스크롤되는지 이 스테이지로 검증 가능해요.
- 구간①(시작 지점)과 구간⑤(도착 지점)에서 카메라가 스테이지 경계를 넘어가지 않고 멈추는지 확인이 필요해요.

---

## 6. 테스트 체크리스트

- [ ] 구간①에서 위험 요소 없이 조작에 익숙해질 수 있는가
- [ ] 구간②의 갭이 기본 점프만으로 안정적으로 건널 수 있는 거리인가 (너무 쉽거나 너무 빡빡하지 않은지)
- [ ] 구간③의 26→30 4칸 점프가 코요테 타임/가변 점프로 클리어 가능한 난이도인가 (불가능하면 안 됨)
- [ ] 구간④의 연속 조합이 부당하게 어렵게 느껴지지 않는가
- [ ] 구간⑤(55~58, 4칸 갭)가 좌절감보다는 성취감을 주는 난이도인가 — 최대 점프 거리 한계치에 가까우므로 우선적으로 점검
- [ ] 전체 플레이 타임이 너무 길거나 짧지 않은가 (1분~2분 내외 권장)
