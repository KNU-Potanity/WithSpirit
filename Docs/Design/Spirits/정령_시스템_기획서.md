# 정령 시스템 기획서

## 0. 문서 목적

이 문서는 확장 단계 핵심 시스템인 **정령**(플레이어를 따라다니며 돕는 동료)의 종류, 상호작용 방식, 등장 시점을 정의합니다.

- `플랫포머_게임_기획서_확장기능.md`에서 채택된 확장 기능의 상세 설계입니다.
- 정령 관련 수치(스탯 항목)는 `스탯_기획서.md`에 정리되어 있으며, 이 문서는 종류·역할·설정(세계관) 중심으로 작성합니다.
- 정령이 등장하는 테마별 시점은 `월드_스테이지_구성.md`를 참고하세요.

---

## 1. 정령 개요

| 항목 | 내용 |
|---|---|
| 정체 | 날아다니며 플레이어를 따라다니는, 플레이어를 돕는 동료 존재 |
| 체력 | 없음 (공격 대상이 되지 않고, 파괴·소멸되지 않음) |
| 역할 | 플레이어 대신 공격하거나 발판을 생성 |

> 플레이어 본인은 이동과 점프만 가능하고, 공격이나 특수 능력은 전부 정령을 통해 이루어집니다. (이동·점프 수치는 `캐릭터컨트롤_스펙.md` 기준 변경 없음)

---

## 2. 상호작용 방식

- 상호작용 가능한 대상(설치 장소, 몬스터 등)에 마우스 포인터를 가져다 대면 **마커**가 표시됩니다.
- 마커가 뜬 상태에서 클릭하면 아래처럼 동작합니다.

| 대상 | 클릭 시 동작 |
|---|---|
| 설치 장소 | 정령이 그 자리에 플랫폼을 생성 |
| 몬스터 | 정령이 공격해 몬스터에게 데미지 |

- 공격/기본 상호작용은 마우스 왼쪽 클릭, 정령 선택은 마우스 오른쪽 클릭입니다. (`캐릭터컨트롤_스펙.md` 조작키 항목 참고)

---

## 3. 정령의 종류

### 3.1 기본 정령 (1개, 원본)

- 게임 시작부터 항상 함께합니다.
- 공격과 플랫폼 생성 기능을 **모두** 사용할 수 있는 올라운드 정령입니다.

### 3.2 추가 정령 (분신, 총 6종 중 3종 장착)

- 기본 정령의 분신이라는 설정이며, 테마 2부터 등장하기 시작해 테마 3에서 최대 개수(3개)까지 함께합니다.
- 한 번에 함께하는 추가 정령 수는 최대 3개이며, 아래 6종 중 3종을 선택해 장착합니다.
- 기본 정령과 달리 공격 또는 플랫폼 중 **한쪽에만 특화**되어 있습니다.

| 분류 | 종류 (3종) | 비고 |
|---|---|---|
| 공격 특화 | 폭발 / 스턴 / 체인 | 각각 다른 공격 방식 (범위 폭발, 상태이상, 연쇄 공격) |
| 플랫폼 특화 | 이속 증가 / 2단 점프 / 초당 데미지 발판 | 정령이 생성한 플랫폼에 탑승 시 효과 부여 |

> 정령마다 구분되는 색상을 부여할 예정입니다 (아트 확정 시 `아트스타일_가이드.md`에 반영).

### 3.3 기본 정령 vs 추가 정령

| 구분 | 기본 정령 | 추가 정령 |
|---|---|---|
| 기능 범위 | 공격 + 플랫폼 모두 | 공격 또는 플랫폼 중 하나 |
| 등장 시점 | 게임 시작부터 | 테마 2부터 (중간부터) |
| 개수 | 1개 (고정) | 최대 3개 (6종 중 선택) |

## 4. 플레이어와 정령의 관계 (세계관·감성 설정)

기능적으로는 무기·패시브 스킬과 다르지 않지만, 이 게임에서는 정령을 **플레이어와 함께 고생하며 스테이지를 뚫고 나가는 동료(자아의 일부)**로 설정합니다.

> 기능은 동일해도 세계관과 연출에 따라 플레이어에게 다르게 다가올 수 있다는 것이 이 설정의 의도입니다. 추후 스토리(`월드_스테이지_구성.md` 2장)와 연결됩니다.
