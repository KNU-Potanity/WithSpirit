# 정령 시스템 기획서

## 0. 문서 목적

> 마지막 수정일: 2026-07-23 (기본 정령 멈춤/이동/상호작용 Animator 구성 완료 — ver4)

이 문서는 확장 단계 핵심 시스템인 **정령**(플레이어를 따라다니며 돕는 동료)의 종류, 상호작용 방식, 등장 시점을 정의합니다.

- `플랫포머_게임_기획서_확장기능.md`에서 채택된 확장 기능의 상세 설계입니다.
- 정령 관련 수치(스탯 항목)는 `스탯_기획서.md`에 정리되어 있으며, 이 문서는 종류·역할·설정(세계관) 중심으로 작성합니다.
- 정령이 등장하는 테마별 시점은 `월드_스테이지_구성.md`를 참고하세요.

---

## 1. 정령 개요

| 항목 | 내용 |
|---|---|
| 정체 | 날아다니며 플레이어를 따라다니는, 플레이어를 돕는 동료 존재 |
| 체력 | 없음 (공격 대상이 되지 않고, 파괴·소멸되지 않음) |
| 역할 | 플레이어 대신 공격하거나 발판을 생성 |

> 플레이어 본인은 이동과 점프만 가능하고, 공격이나 특수 능력은 전부 정령을 통해 이루어집니다. (이동·점프 수치는 `캐릭터컨트롤_스펙.md` 기준 변경 없음)

---

## 2. 상호작용 방식

- 상호작용 가능한 대상(설치 장소, 몬스터 등)에 마우스 포인터를 가져다 대면 **마커**가 표시됩니다.
- 마커가 뜬 상태에서 클릭하면 아래처럼 동작합니다.

| 대상 | 클릭 시 동작 |
|---|---|
| 설치 장소 | 정령이 그 자리에 플랫폼을 생성 |
| 몬스터 | 정령이 공격해 몬스터에게 데미지 |

- 공격/기본 상호작용은 마우스 왼쪽 클릭, 정령 선택은 마우스 오른쪽 클릭입니다. (`캐릭터컨트롤_스펙.md` 조작키 항목 참고)

---

## 3. 정령의 종류

### 3.1 기본 정령 (1개, 원본)

- 게임 시작부터 항상 함께합니다.
- 공격과 플랫폼 생성 기능을 **모두** 사용할 수 있는 올라운드 정령입니다.

### 3.2 추가 정령 (분신, 총 6종 중 3종 장착)

- 기본 정령의 분신이라는 설정이며, 테마 2부터 등장하기 시작해 테마 3에서 최대 개수(3개)까지 함께합니다.
- 한 번에 함께하는 추가 정령 수는 최대 3개이며, 아래 6종 중 3종을 선택해 장착합니다.
- 기본 정령과 달리 공격 또는 플랫폼 중 **한쪽에만 특화**되어 있습니다.

| 분류 | 종류 (3종) | 비고 |
|---|---|---|
| 공격 특화 | 폭발 / 스턴 / 체인 | 각각 다른 공격 방식 (범위 폭발, 상태이상, 연쇄 공격) |
| 플랫폼 특화 | 이속 증가 / 2단 점프 / 초당 데미지 발판 | 정령이 생성한 플랫폼에 탑승 시 효과 부여 |

> 정령마다 구분되는 색상을 부여할 예정입니다 (아트 확정 시 `아트스타일_가이드.md`에 반영).

### 3.3 기본 정령 vs 추가 정령

| 구분 | 기본 정령 | 추가 정령 |
|---|---|---|
| 기능 범위 | 공격 + 플랫폼 모두 | 공격 또는 플랫폼 중 하나 |
| 등장 시점 | 게임 시작부터 | 테마 2부터 (중간부터) |
| 개수 | 1개 (고정) | 최대 3개 (6종 중 선택) |

## 4. 플레이어와 정령의 관계 (세계관·감성 설정)

기능적으로는 무기·패시브 스킬과 다르지 않지만, 이 게임에서는 정령을 **플레이어와 함께 고생하며 스테이지를 뚫고 나가는 동료(자아의 일부)**로 설정합니다.

> 기능은 동일해도 세계관과 연출에 따라 플레이어에게 다르게 다가올 수 있다는 것이 이 설정의 의도입니다. 추후 스토리(`월드_스테이지_구성.md` 2장)와 연결됩니다.

## 5. 애니메이션

### 5.1 애니메이션 종류 및 스펙

| 종류 | 설명 | 재생 속도 |
|---|---|---|
| 멈춤 (기본) | 정령이 제자리에 떠 있는 대기 상태 | 기준 속도 (10프레임) |
| 이동 | 정령이 플레이어를 따라 이동하는 상태 | 멈춤의 2배 속도 |
| 공격 | 정령이 공격을 실행하는 상태 | 기준 속도 (10프레임) |
| 상호작용 (변신 효과 적용) | 정령이 상호작용(발판 생성 등)을 실행하는 상태, 변신 효과가 함께 적용됨 | 기준 속도 (10프레임) |

- **일반(기준) 프레임레이트는 10프레임**입니다. 이동 애니메이션만 예외적으로 멈춤 대비 2배 속도(체감상 더 빠른 파닥임)로 재생합니다.
- 상호작용 애니메이션은 단순 동작 재생이 아니라 **변신 효과가 함께 적용**되는 것이 특징입니다 (구체적인 변신 연출은 아트 확정 후 추가).

### 5.2 진행 상황

- **정령이 플레이어를 따라다니는 이동 구현 완료** (2026-07-16): `Assets/_Project/Scripts/Fairy/FairyMovement.cs` — `SmoothDamp`로 플레이어+오프셋 위치를 부드럽게 추적, `Sin` 곡선으로 위아래 Hover 효과, 플레이어 반대편에 있으면 좌우 반전. 공격/플랫폼 생성 로직은 아직 미구현.
- **정령 스탯이 `ScriptableObject`로 구현됨** (2026-07-16): `MainFairyData`/`AttackFairyData`/`PlatformFairyData` (`Assets/_Project/Scripts/ScriptableObjects/FairyData/`)가 각각 2.1~2.3절 수치 항목과 1:1로 대응하도록 만들어져 있습니다. 자세한 필드는 `스크립트_설명서.md` 참고.
- **기본 정령 — 멈춤(기본) 애니메이션 제작 완료** (2026-07-14)
  - 스프라이트: `Assets/_Project/Art/Fairies/fairy_base_idle_01.png` ~ `03.png` (Sprite, PPU=16, Point Filter)
  - 클립: `Assets/_Project/Animations/Fairies/anim_fairy_base_idle.anim`
  - 프레임 순서: 01 → 02 → 03 → 02 → 01, 프레임당 0.1초, 총 0.5초, 루프 재생 (10프레임 기준)
  - 이 클립이 **정령의 모든 애니메이션 제작의 기본 틀**이 됩니다 (동일한 프레임 순서 패턴을 공격/상호작용/이동에도 적용 예정).
- **기본 정령 — 멈춤/이동/상호작용 Animator 구성 완료** (2026-07-23)
  - 컨트롤러: `Assets/_Project/Animators/Fairies/AC_Fairy_Base.controller`
  - 파라미터: `Speed`(Float), `Interact`(Trigger), `Arrived`(Trigger)

  | State | 사용 클립 | 재생 속도 | 전환 조건 |
  |---|---|---|---|
  | Idle (멈춤, 기본) | `anim_fairy_base_idle` | 1배속 | `Speed` ≤ 0.01일 때 |
  | Move (이동) | `anim_fairy_base_idle` | **2배속** | `Speed` > 0.01일 때 (플레이어 이동 또는 정령 공격 시) |
  | InteractMove (상호작용 — 가는 과정) | `anim_fairy_base_idle` | **2배속** | 어느 상태에서든 `Interact` 트리거 시 진입 |
  | InteractArrive (상호작용 — 도착) | `anim_fairy_base_idle` | 1배속 | `Arrived` 트리거 시 |
  | Interact (상호작용 — 변신 효과) | `anim_fairy_base_interact` | 1배속 | InteractArrive 재생이 끝나면(Exit Time) 자동 진입, 끝나면 Idle로 복귀 |

  - "이동" 애니메이션은 플레이어 이동 시뿐 아니라 **정령이 몬스터를 공격할 때도** 재생되도록 설계되어 있습니다 (`Speed` 파라미터를 공격 중에도 true로 설정하는 방식으로 구현 예정).
  - "상호작용"은 플랫폼 생성 마커 클릭 시 마커 위치로 이동하는 동안(2배속 idle) → 도착 후 잠깐(1배속 idle) → 실제 변신 효과 애니메이션(`anim_fairy_base_interact`) 순으로 재생됩니다.
  - `Interact`/`Arrived` 트리거는 정령 상호작용 로직(`FairyInteractionController.cs`, 아직 미구현)에서 호출할 예정입니다.
