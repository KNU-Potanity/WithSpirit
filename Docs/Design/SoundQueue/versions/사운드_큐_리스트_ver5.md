# 사운드 큐 리스트

## 0. 문서 목적

이 문서는 게임 안에서 **어떤 상황에 어떤 느낌의 소리가 필요한지**를 기획 관점에서 미리 정리한 문서입니다.

- 실제 음원 제작/선정은 아트(또는 사운드 담당)가 하지만, 무엇이 필요한지 목록을 만드는 건 기획의 역할이라 먼저 작성합니다.
- MVP 단계에는 사운드가 구현되지 않지만, 어떤 이벤트에 소리가 필요한지는 핵심 기능 설계 시점에 이미 정해져 있으므로 미리 정리해둡니다.
- `기술기획서.md` 4.6절의 이벤트 시스템과 1:1로 매칭되도록 작성했습니다.
- 2026-07-09 개정: 정령 시스템이 채택되면서 정령/몬스터/하트 관련 신규 사운드 큐를 4장에 추가했습니다.

---

## 1. 사운드 큐 설계 원칙

- **짧고 즉각적으로**: 플랫포머는 반응 속도가 중요한 장르라, 효과음은 0.5초 이내의 짧은 소리를 기본으로 합니다.
- **위험 신호와 혼동되지 않게**: `아트스타일_가이드.md`의 색상 원칙(위험=빨강 계열)과 마찬가지로, 위험하지 않은 이벤트(점프, 클리어 등)의 사운드는 경고처럼 들리는 음색(급격한 고음 경고음 등)을 피합니다.
- **반복 재생을 고려**: 점프처럼 자주 발생하는 이벤트는 반복 재생 시 거슬리지 않는 짧고 단조로운 소리로 설계합니다.

---

## 2. MVP 핵심 이벤트 기반 사운드 큐

`기술기획서.md`에 정의된 이벤트(점프했다, 장애물에 닿았다, 도착 지점에 도달했다)를 기준으로, 각 이벤트에 필요한 사운드를 정리했습니다.

| 이벤트 | 발생 시점 | 사운드 큐 (파일명) | 느낌/설명 | 우선순위 |
|---|---|---|---|---|
| 점프 | 점프 입력 성공 시 | `sfx_jump.wav` | 가볍고 경쾌한 단음, 반복 재생에도 거슬리지 않게 | 높음 |
| 착지 | 공중에서 발판에 닿는 순간 | `sfx_land.wav` | 점프보다 낮은 음, 무게감 있는 짧은 소리 | 중간 (없어도 MVP는 성립) |
| 장애물 접촉(사망) | 즉사 장애물 접촉 시 | `sfx_hit.wav` | 부정적이지만 과하게 자극적이지 않은 소리 (반복 청취 가능성 높음) | 높음 |
| 리스폰 | 리스폰 위치로 복귀하는 순간 | `sfx_respawn.wav` | 사망음과 구분되는, 중립적인 재시작 느낌 | 중간 |
| 도착 지점 도달 (클리어) | 목표 지점 접촉 시 | `sfx_clear.wav` | 밝고 상승하는 음, 성취감을 주는 소리 | 높음 |

## 3. 확장 기능 단계 예상 사운드 큐 (조건부)

`플랫포머_게임_기획서_확장기능.md`의 항목이 실제로 채택될 경우 필요한 사운드입니다. 해당 기능이 선택되지 않으면 이 항목들은 만들지 않아도 됩니다.

| 관련 확장 기능 | 이벤트 | 사운드 큐 (파일명) | 느낌/설명 |
|---|---|---|---|
| 파워업 | 파워업 획득 | `sfx_powerup.wav` | 상승하는 음, 클리어음보다는 짧게 |
| UI | 일시정지 메뉴 열기/닫기 | `sfx_ui_pause.wav` | 게임플레이 사운드와 톤이 다른, UI 전용 음색 |
| UI | 버튼 클릭 | `sfx_ui_click.wav` | 짧고 단조로운 클릭음 |
| 이동 확장 (대시 등) | 대시 발동 | `sfx_dash.wav` | 빠르고 마찰감 있는 소리 |

## 4. 확장 단계(정령 시스템) 신규 사운드 큐 — 채택 (2026-07-09 추가)

`정령_시스템_기획서.md`, `몬스터_기획서.md`, `발판_확장_기획서.md`, `월드_스테이지_구성.md`에서 채택된 시스템에 대응하는 사운드입니다.

### 4.1 정령 관련

| 이벤트 | 발생 시점 | 사운드 큐 (파일명) | 느낌/설명 |
|---|---|---|---|
| 마커 표시 | 상호작용 가능한 대상에 마우스를 올릴 때 | `sfx_marker_hover.wav` | 아주 짧고 은은한 알림음 |
| 정령 선택 전환 | 마우스 오른쪽 클릭으로 정령 변경 | `sfx_spirit_select.wav` | 전환감이 느껴지는 짧은 음 |
| 정령 공격 - 폭발 | 폭발 특화 정령 공격 시 | `sfx_spirit_explosion.wav` | 묵직한 폭발음 |
| 정령 공격 - 스턴 | 스턴 특화 정령 공격 시 | `sfx_spirit_stun.wav` | 전기/충격 느낌의 짧은 음 |
| 정령 공격 - 체인 | 체인 특화 정령 공격 시 | `sfx_spirit_chain.wav` | 연쇄적으로 이어지는 타격음 |
| 정령 플랫폼 생성 | 설치 장소 클릭으로 플랫폼 생성 시 | `sfx_spirit_platform_spawn.wav` | 가볍게 나타나는 느낌의 소리 |

### 4.2 몬스터 관련

| 이벤트 | 발생 시점 | 사운드 큐 (파일명) | 느낌/설명 |
|---|---|---|---|
| 몬스터 처치 | 정령 공격으로 몬스터 처치 시 | `sfx_monster_defeat.wav` | 타격감 있는 짧은 소리 |
| 몬스터 접촉 피격 | 몬스터에 닿아 플레이어가 데미지를 입을 때 | `sfx_player_hit.wav` | 장애물 접촉음(`sfx_hit.wav`)과는 구분되는 음색 |
| 디버프 부여 | 디버프형 몬스터(슬라임 등) 접촉 시 | `sfx_debuff.wav` | 둔하고 끈적한 느낌의 소리 |
| 원거리 피격 | 원거리 몬스터의 투사체에 맞았을 때 | `sfx_ranged_hit.wav` | 접촉 피격음과 구분되는 음색 |
| 보스 등장 | 보스(밤 나무) 스테이지 진입 시 | `sfx_boss_intro.wav` | 긴장감을 주는 연출용 사운드 (상세는 보스 설계 시 확정) |
| 보스 처치 (게임 클리어) | 최종 보스 처치 시 | `sfx_boss_defeat.wav` | 가장 강한 성취감을 주는 사운드, `sfx_clear.wav`보다 임팩트 크게 |

### 4.3 체력/발판 관련

| 이벤트 | 발생 시점 | 사운드 큐 (파일명) | 느낌/설명 |
|---|---|---|---|
| 하트 감소 | 낙사 외 데미지로 하트가 줄어들 때 | `sfx_heart_lost.wav` | `sfx_player_hit.wav`와 별개로, 체력 UI 반응용 소리 |
| 하트 소진 (게임 오버) | 하트가 모두 소진됐을 때 | `sfx_gameover.wav` | 부정적이되 과하지 않은 마무리 사운드 |
| 무너지는 발판 | 무너지는 발판을 밟아 무너질 때 | `sfx_platform_collapse.wav` | 부서지는 느낌의 소리 |
| 스탯 변화 발판 | 스탯 변화 발판을 밟았을 때 | `sfx_platform_statchange.wav` | 버프/디버프 여부에 따라 톤이 달라질 수 있음 (추후 세분화) |

## 7. 다음 단계

1. 사운드 담당(아트 또는 별도 인원)이 정해지면, 이 문서의 느낌/설명 칸을 기준으로 실제 음원 제작 또는 무료/유료 음원 라이브러리에서 선정 (소스 추천 및 라이선스 기록은 `에셋_출처_라이선스_관리.md` 참고)
2. 음원이 준비되면 `Audio/SFX`, `Audio/BGM` 폴더에 파일명 그대로 저장 (`에셋_네이밍_관리규칙.md` 폴더 구조 참고)
3. 프로그래밍 담당이 `기술기획서.md`의 이벤트 시스템에 사운드 재생 코드를 연결
4. 4장의 정령/몬스터/체력 관련 사운드는 해당 시스템 구현과 함께 순차적으로 연결
