## 5. AI 이동 로직

공중형(벌)을 제외한 모든 몬스터는 **Patrol(순찰) → Chase(추격) → Attack(공격)** 상태 머신으로 동작합니다 (스크립트별 세부 조건은 `스크립트_설명서.md` 참고).

| 상태 | 공통 동작 |
|---|---|
| Patrol | 감지 범위 밖일 때 제자리 순찰 (벽·낭떠러지 감지 시 방향 전환) |
| Chase | 감지 범위 안 + 경로가 막히지 않았을 때 플레이어를 향해 이동 |
| Attack | 공격 사거리 안에서 정지 → 쿨타임마다 애니메이션 재생 → `AttackAnimDelay`초 뒤(예비동작) 범위 안이면 데미지 적용 |

- 몬스터의 공격 판정은 좌우 방향으로만 들어갑니다 (애니메이션이 좌우 모션만 있어, 몬스터 머리 위에 있으면 공격 판정 제외). 정령이 몬스터를 공격하는 쪽에는 이 제약이 없습니다.
- "같은 플랫폼" 판정은 몬스터·플레이어 발밑 레이캐스트로 얻은 바닥 Y좌표를 비교해 이뤄집니다.

### 5.1 공중형 (벌) — 구현 완료 (`FloatingMonsterMovement.cs`)

지형에 구애받지 않고 `SmoothDamp`로 자유롭게 비행하며, "같은 플랫폼" 판정 대신 직선 레이캐스트(Line of Sight)로 장애물 유무만 확인합니다. 그 외 Patrol/Chase/Attack 흐름은 공통 로직과 동일합니다.

### 5.2 디버프형 (슬라임) — 구현 완료 (`DebuffMonsterMovement.cs`)

공통 상태 머신과 동일하되 "같은 플랫폼" 판정 없이 단순 감지 범위만 사용합니다. 공격 명중 시 데미지+넉백에 더해 `PlayerMovement.ApplySlowDebuff(감소율, 지속시간)`으로 둔화 디버프를 적용합니다 (수치는 `스탯_기획서.md` 4.1절).

### 5.3 원거리형 (스켈레톤) — 구현 완료 (`RangedMonsterMovement.cs` + `MonsterProjectile.cs`)

공격 사거리 안에서 `RangedMonsterData.ProjectilePrefab`을 자식 `FirePoint`에서 플레이어 방향으로 생성합니다. 투사체(`MonsterProjectile.cs`)는 직선 이동하며, 바닥·플레이어 접촉 또는 `lifetime`(기본 5초) 경과 시 소멸하는 범용 구조라 보스의 밤송이 투척에도 재사용됩니다.

### 5.4 사망 시 이동 스크립트 비활성화 — 구현 완료

`MonsterHealth.Die()`가 `IMonsterMovement` 마커 인터페이스를 구현한 컴포넌트를 전부 찾아 일괄 비활성화합니다. 새 몬스터 이동 스크립트도 이 인터페이스만 구현하면 자동으로 포함됩니다.

### 5.5 식충식물 — 구현 완료 (`PlantMonsterMovement.cs`)

순찰 없이 Idle/Attack 2개 상태만 가지며, `FreezePositionX` 제약으로 애초에 좌우 이동이 불가능합니다. 공격 범위 안에 들어오면 예비동작 후 데미지를 입힙니다.

### 5.6 밤송이 (보스 소환 개체) — 구현 완료 (`ChestnutMonsterMovement.cs`)

Patrol/Chase 후, 사거리 안에서 실제 포물선 발사 공식(`CalculateParabolicVelocity`)으로 플레이어를 향해 점프 공격합니다. 명중 시 자폭, 빗나가면 Chase로 복귀. `MonsterHealth`+클릭 마커가 포함되어 있어 정령 공격으로 미리 제거할 수 있습니다.

## 6. 애니메이션 구현 방식

| 애니메이션 | 구현 방식 |
|---|---|
| 멈춤/걷기 | Animator State (Idle/Walk 클립 + `Speed` 파라미터) |
| 공격 | Animator State (Attack 클립 + `Attack` 트리거) |
| 데미지 받음/죽음 | Animator가 아닌 `MonsterHealth.cs`가 처리 (피격 시 빨간색 점멸, 사망 시 알파 페이드 아웃 후 제거) |

> "지금 뭘 하는지"는 Animator가, "상태 변화 피드백"은 스크립트가 담당하도록 나눠서, 몬스터마다 Idle/Walk/Attack 클립만 갈아끼우면 재사용되도록 했습니다.

### 6.1 Animator Controller — 구현 완료

7종 전체(`AC_Monster_이름.controller`) 생성 및 Idle/Walk/Attack 클립 연결이 완료되어 있습니다. 좌우 반전은 원칙상 `MonsterFacing.cs`(모든 클립이 오른쪽만 사용) 담당이지만, 실제로는 각 이동 스크립트가 자체 처리 중이라 아직 부착되어 있지 않습니다.

### 6.2 Animator 연동 예시 — 버섯

`GroundMonsterMovement.cs`에 `Speed`/`Attack` 파라미터 반영과 공격 중 정지 로직이 적용되어 있습니다. 같은 패턴을 다른 지상 근접몹에도 동일 적용할 예정입니다.

### 6.3 스탯 데이터 — ScriptableObject 기반

`MonsterData`(공통) + `GroundMonsterData`/`FloatingMonsterData`/`RangedMonsterData`/`DebuffMonsterData`(유형별)로 구현되어 있으며, `스탯_기획서.md` 3장 수치와 필드가 대응됩니다. `ProjectileTypes`/`DebuffTypes` enum은 아직 값이 비어있습니다.

### 6.4 근접 지상 몬스터 프리팹 — 구현 완료

| 항목 | 경로 |
|---|---|
| 공통 템플릿 | `Prefabs/Entities/Monsters/GroundMonsterPrefab.prefab` |
| 버섯·나무골렘·식충식물·벌·슬라임·스켈레톤·밤송이 | 각각 `Prefabs/Entities/Monsters/{이름}.prefab` |

> ⚠️ `스탯_기획서.md` 최신 수치와 실제 에셋 값이 여전히 다른 몬스터가 있습니다 (3.6절 참고). 데이터 에셋을 문서 확정값으로 맞추는 작업이 `ToDoList.md`에 남아있습니다.

### 6.5 플레이어·설치 장소 프리팹화 — 구현 완료

`PlayerStartMarker.prefab`(`Prefabs/Entities/Player/`), `PlatformPlace.prefab`(`Prefabs/Terrain/`)로 정리되었습니다. 다만 기존 설치 장소 12개 중 7개는 아직 이 프리팹에 연결되지 않은 개별 오브젝트로 남아있습니다.

## 7. 보스(밤 나무) 패턴 설계

돌진(회피형) / 펀치(근접) / 밤송이 투척(원거리) 세 패턴으로, 정령의 서로 다른 기능(플랫폼·거리조절·공격)을 각각 파훼법으로 쓰도록 설계했습니다.

| 패턴 | 내용 | 파훼법 |
|---|---|---|
| 돌진 | 한쪽 방향으로 화면 끝까지 직선 돌진 | 플랫폼을 설치해 뛰어넘기 |
| 펀치 | 근접 시 제자리 펀치 | 거리를 벌려 회피 |
| 밤송이 투척 | 플레이어에게 날아드는 밤송이 소환 | 닿기 전 정령 공격으로 제거 |

### 7.1 설계 의도

세 패턴은 각자 독립된 쿨타임을 가지며 동시에 발동하지 않고, 조건 충족 시에도 매번 랜덤으로 발동 여부를 재판정해 패턴을 예측하기 어렵게 설계했습니다 (실제 구현은 7.5·7.6절 참고 — 다른 방식으로 구현됨).

### 7.2 공용 구조

투사체 시스템(`MonsterProjectile.cs`, 5.3절)이 스켈레톤 화살로 이미 구현되어 있어 밤송이 투척에도 그대로 재사용됩니다.

### 7.3 설계 목표 수치

| 패턴 | 목표 쿨타임 | 목표 배속/사거리 |
|---|---|---|
| 돌진 | 10초 | 평상시 이동속도의 2배 |
| 펀치 | 5초 (사거리 안일 때만) | 사거리 4 |
| 밤송이 투척 | 15초 | 3마리 동시 소환, 개체당 체력2/이속1/호밍거리1.5 |

### 7.4 설계 발동 로직

조건을 충족해도 매번 랜덤으로 발동 여부를 재판정하고, 여러 패턴이 동시에 조건을 충족하면 그중 랜덤으로 하나를 선택하도록 설계했습니다 (실제 구현은 랜덤 없이 동작 — 7.5절 참고).

### 7.5 실제 구현 현황 — 돌진·펀치 (`BossMonsterMovement.cs` + `BossMonsterData.cs`)

| 항목 | 설계 | 실제 구현 |
|---|---|---|
| 돌진 배속 | 2배 | **5배** |
| 돌진 쿨타임 | 10초 | **5초** |
| 펀치 사거리 / 쿨타임 | 별도 4 / 5초 | 별도 필드 없이 기존 `AttackRangeX`(3)·`CoolTime`(3) 재사용 |
| 발동 방식 | 조건 충족해도 랜덤 판정 | **랜덤 없음** — 조건 충족 시 즉시·항상 발동, Chase/펀치를 끊고 우선권 획득 |

- 돌진 전 0.8초 정지(경고 연출) 후 발동하며, 벽에 부딪히거나 최대 3초 경과 시 종료됩니다.
- ⚠️ 돌진이 경로상의 정령 플랫폼을 강제로 해제시켜, "플랫폼으로 뛰어넘기" 파훼법과 충돌할 수 있습니다 — 의도한 동작인지 확인이 필요합니다 (`ToDoList.md` 참고).

### 7.6 실제 구현 현황 — 밤송이 투척

`BossMonsterData`에 범용 소환 패턴 리스트(`spawnPatterns`)가 추가되어, 밤송이 전용이 아닌 재사용 가능한 구조로 구현되었습니다. 소환 간격이 설계(15초)와 다르게 **5초**로 되어 있어(개수 3마리는 설계와 일치) 돌진(5초)·펀치와 자주 겹칠 수 있어 실제 플레이로 밸런스 확인이 필요합니다. 소환된 밤송이는 5.6절의 독립 몬스터로 동작합니다.
