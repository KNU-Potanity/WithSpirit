MVP 단계의 발판(일반 발판, 즉사 장애물)에 이어, 확장 단계에서 추가되는 발판 종류를 정리합니다. 기존 발판 정의는 `플랫포머_게임_기획서.md` 2.2절을 참고하세요.

## 1. 신규 발판 종류

| 종류 | 동작 방식 | 비고 |
|---|---|---|
| 이동 발판 | 전방향으로 움직이는 발판 (좌우뿐 아니라 상하 등 모든 방향 이동 가능) | |
| 무너지는 발판 | **밟은 지 1초 후에 아래로 떨어짐** (2026-08-12 수치 확정) | |
| 스탯 변화 발판 | 밟으면 플레이어 스탯이 변화 — 아래 3종으로 확정 (2026-08-12) | 2절 참고 |

### 1.1 스탯 변화 발판 — 3종 확정 (2026-08-12)

| 종류 | 효과 |
|---|---|
| 이속 증가 발판 | 밟고 3초 동안 이동 속도 1.5배 |
| 점프력 증가 발판 | 원래 점프 높이의 1.5배만큼 더 높이 점프 |
| 데미지 무효화 발판 | 데미지 1번을 막아주는 장막 부여 (시간제한 없이, 1회 소모되면 사라짐) |

## 2. 정령이 생성하는 플랫폼과의 관계

- 위 표는 스테이지에 미리 배치된 발판입니다.
- 정령(플랫폼 특화 3종)이 생성하는 발판은 `정령_시스템_기획서.md` 3.2절에 정의되어 있으며, **1.1절의 스탯 변화 발판 3종(이속 증가/점프력 증가/데미지 무효화)과 동일한 효과**를 냅니다 — 즉 정령이 만드는 플랫폼도 스테이지에 미리 배치된 스탯 변화 발판과 같은 시스템을 공유합니다. **설치 장소**라는 전용 지점에서만 생성됩니다.
- 설치 장소는 스테이지 요소 중 하나로 `월드_스테이지_구성.md` 3장에서 관리합니다.

---

## 3. 게임 오버 요소와의 구분

발판이 아닌 스테이지의 위험 요소는 별도로 관리합니다.

- 가시, 낙사 (기존 MVP)
- 원거리 공격, 접촉 데미지, 디버프 (몬스터 관련, 확장 — `몬스터_기획서.md` 참고)
