# 발판 확장 기획서

## 0. 문서 목적

MVP 단계의 발판(일반 발판, 즉사 장애물)에 이어, 확장 단계에서 추가되는 발판 종류를 정리합니다. 기존 발판 정의는 `플랫포머_게임_기획서.md` 2.2절을 참고하세요.

---

## 1. 신규 발판 종류

| 종류 | 동작 방식 | 비고 |
|---|---|---|
| 이동 발판 | 전방향으로 움직이는 발판 (좌우뿐 아니라 상하 등 모든 방향 이동 가능) | |
| 무너지는 발판 | 밟으면 아래쪽으로 무너져 사라짐 | |
| 스탯 변화 발판 | 밟으면 플레이어 스탯이 변화 (예: 체력 회복, 공격력 증가 등 버프·디버프) | 구체적 효과는 추후 확정 |

---

## 2. 정령이 생성하는 플랫폼과의 관계

- 위 표는 스테이지에 미리 배치된 발판입니다.
- 정령(플랫폼 특화 3종)이 생성하는 발판은 `정령_시스템_기획서.md` 3.2절에 정의되어 있으며 (이속 증가 / 2단 점프 / 초당 데미지 발판), **설치 장소**라는 전용 지점에서만 생성됩니다.
- 설치 장소는 스테이지 요소 중 하나로 `월드_스테이지_구성.md` 3장에서 관리합니다.

---

## 3. 게임 오버 요소와의 구분

발판이 아닌 스테이지의 위험 요소는 별도로 관리합니다.

- 가시, 낙사 (기존 MVP)
- 원거리 공격, 접촉 데미지, 디버프 (몬스터 관련, 확장 — `몬스터_기획서.md` 참고)

---

## 4. 다음 단계

- 발판별 구체적인 수치(이동 속도, 무너지기까지 걸리는 시간, 스탯 변화량)는 `스탯_기획서.md`와 함께 확정
- 신규 발판 3종에 대응하는 타일·오브젝트 아트 제작 필요 (`아트스타일_가이드.md`, `에셋_네이밍_관리규칙.md` 규칙 적용)
