# 아트 스타일 가이드 — MVP

## 0. 문서 목적

이 문서는 캐릭터, 배경, 이펙트 등 시각 요소를 제작할 때 따라야 할 **최소한의 톤앤매너와 규칙**을 정리합니다.

- 지금은 핵심 기능만 혼자 구현하는 단계라 실제 아트 제작은 나중이지만, 이후 아트 부원이 합류했을 때 기준 없이 제각각 그리는 것을 막기 위해 미리 작성합니다.
- 구체적인 그림 실력보다는 **무엇을, 어떤 기준으로 그릴지**에 초점을 둡니다.

> **가정**: 별도로 정해진 아트 방향이 없어서, 동아리 소규모 프로젝트에 가장 적합한 **단순한 픽셀아트 스타일**을 기본값으로 가정했습니다. 다른 스타일(벡터 플랫, 손그림 등)을 원하면 이 문서의 색상/해상도 규칙만 교체하면 됩니다.

---

## 1. 전체 방향성

| 항목 | 방향 |
|---|---|
| 그림체 | 단순한 픽셀아트 (디테일보다 가독성 우선) |
| 분위기 | 밝고 명확한 톤 (어둡고 무거운 분위기보다 캐주얼한 느낌) |
| 핵심 원칙 | 멀리서도, 빠르게 움직이는 와중에도 무엇인지 즉시 구분되어야 한다 |

> 플랫포머는 빠른 판단이 필요한 장르라서, 아트도 예쁜 것보다 빨리 인식되는 것이 우선이에요. 디테일이 많으면 오히려 위험 요소(가시 등)와 배경이 헷갈릴 수 있습니다.

---

## 2. 해상도 / 규격

| 항목 | 값 | 비고 |
|---|---|---|
| 기준 타일 크기 | 64×64px | 아트 제작 권장 해상도. Unity 구현에서의 1타일(=1유닛, PPU=16 기반)과는 별개의 아트 사이드 수치 |
| 캐릭터 스프라이트 권장 크기 | 약 51×96px (가로 0.8타일 × 세로 1.5타일) | 캐릭터 히트박스와 동일한 비율로 제작 (시각 크기와 충돌 크기를 크게 다르게 만들지 않기) |
| 파일 포맷 | PNG (투명 배경, 알파 채널 포함) | |
| 핀(Pivot) 기준 | 캐릭터: 발바닥 중앙 / 타일: 좌하단 | Unity에서 배치 시 좌표 계산 일관성 유지 |

## 3. 색상 가이드

### 3.1 기본 팔레트 원칙
- 전체 색상 수를 적게 유지 (배경 2~3색, 지형 2~3색, 캐릭터 2~4색 정도로 시작)
- 채도가 높은 색은 **위험 요소에만 예약**해서 사용 (아래 3.2 참고)

### 3.2 요소별 색상 규칙

| 요소 | 색상 방향 | 이유 |
|---|---|---|
| 일반 발판 | 차분한 색 (갈색, 초록, 회색 계열) | 안전한 요소이므로 시각적으로 눈에 띄지 않아도 됨 |
| 즉사 장애물 (가시 등) | 빨간색/주황색 계열, 채도 높게 | 위험은 명확하게 — `캐릭터컨트롤_스펙.md`의 위험한 것은 판정도, 시각도 명확하게 원칙과 동일 |
| 도착 지점 | 채도 높은 색 (예: 노란색, 청록색) — 위험 색(빨강)과는 다른 색 사용 | 목표라는 정보를 위험과 혼동되지 않게 구분 |
| 배경 | 가장 채도가 낮고 어두운/연한 색 | 플레이 요소(발판, 캐릭터)와 명확히 구분되도록 |
| 캐릭터 | 배경/지형과 대비되는 색 (예: 배경이 차가운 톤이면 캐릭터는 따뜻한 톤) | 어떤 배경에서도 캐릭터가 눈에 띄어야 함 |

> 핵심 규칙: **위험(빨강 계열) / 목표(고채도, 빨강이 아닌 색) / 안전(저채도)** 이 세 가지 색상군이 서로 헷갈리지 않게 하는 것이 가장 중요합니다.

---

## 4. 캐릭터 디자인 가이드

- 실루엣만으로 캐릭터의 방향(좌/우)과 상태(서있음/점프 중)가 구분되어야 함
- 최소 필요 애니메이션 (MVP 기준)
 - 대기(Idle)
 - 이동(Walk/Run)
 - 점프 상승
 - 낙하
 - (착지 시 짧은 모션이 있으면 좋지만 필수는 아님)
- 색상 수는 4~6색 이내로 제한 (그림자/하이라이트 포함)

---

## 5. 지형/오브젝트 디자인 가이드

| 오브젝트 | 디자인 기준 |
|---|---|
| 일반 발판 | 타일이 이어 붙었을 때 경계가 부드럽게 연결되도록 (타일 경계가 너무 도드라지지 않게) |
| 즉사 장애물 | 실루엣만 봐도 뾰족하다/위험하다는 느낌이 들도록 (가시는 삼각형 형태 강조) |
| 도착 지점 | 명확한 단일 오브젝트로 (깃발, 문, 별 등 — 발판과 혼동되지 않는 형태) |
| 배경 | 레이어를 1~2개 정도로 단순하게 구성 (멀리 있는 배경은 더 단순하고 흐리게) |

---

## 6. UI 비주얼 가이드 (추후 적용 대비)

- 지금 MVP에는 UI가 없지만, 추후 HUD/메뉴가 추가될 경우를 대비해 미리 톤만 정의
- 폰트: 가독성이 높은 단순한 폰트 (디테일 많은 장식 폰트 지양)
- UI 색상은 게임 플레이 색상(빨강=위험 등)과 겹치지 않게 별도 색상군 사용 (예: 흰색/남색 계열)

---

## 7. 이펙트 가이드 (추후 적용 대비)

- 점프, 착지, 클리어 등 이벤트에 들어갈 이펙트는 **작고 짧게** (화면을 가리지 않도록)
- 색상은 해당 이벤트와 자연스럽게 어울리되, 위험 색(빨강)은 이펙트에 사용하지 않음 (위험 신호와 혼동 방지)

---

## 8. 현재 에셋 적용 현황 (기준)

- MVP 단계에서 **CraftPix SimplePlatformer2D 에셋을 실제로 사용 중**입니다. 별도의 플레이스홀더(단색 사각형) 단계를 거치지 않았습니다.
- 현재 사용 중인 에셋 목록은 `기술기획서.md` 4.7절 참고
- 아트 부원이 합류해 직접 제작한 에셋으로 교체할 경우, 이 문서의 색상/규격 가이드를 기준으로 제작하면 됩니다.
- 해상도 규격 항목의 기준 타일 크기 64×64px는 아트 제작 기준이며, Unity 구현 단위(1타일=1유닛, PPU=16)와는 별개입니다.

---

## 9. 확장 단계 아트 요소 (정령/몬스터/발판)정령 시스템 채택에 따라 확장 단계에서 새로 필요한 아트 요소의 방향성입니다. 구체적인 색상 팔레트(HEX 코드)는 아트 부원 합류 후 확정합니다.

### 9.1 정령

| 항목 | 방향 |
|---|---|
| 색상 구분 | 정령 6종(공격 특화 3 + 플랫폼 특화 3) + 기본 정령 1종, 총 7종을 색상으로 구분 (`정령_시스템_기획서.md` 3장) |
| 실루엣 | 날아다니는 존재이므로 플레이어 캐릭터와 겹치지 않는 작고 동글동글한 실루엣 권장 |
| 감정 표현 | 4장의 세계관 설정(동료·자아)에 맞게, 단순한 도형보다는 표정/움직임으로 생동감을 표현하는 방향 고려 |

### 9.2 몬스터

| 항목 | 방향 |
|---|---|
| 테마별 톤 | 테마 1(마을/도시), 테마 2(변방), 테마 3(숲) 배경 톤에 맞춰 몬스터 색상/분위기 조정 (`월드_스테이지_구성.md` 1장) |
| 위험 신호 | 근거리/원거리/디버프형 몬스터도 기존 3.2절의 위험=고채도(빨강 계열 우선) 원칙을 따르되, 3장의 몬스터별 개성을 해치지 않는 선에서 절충 |
| 보스(밤 나무) | 스테이지 내에서 가장 크고 실루엣이 확실히 구분되는 존재로 디자인 |

### 9.3 신규 발판 (이동/무너짐/스탯변화)

| 항목 | 방향 |
|---|---|
| 이동 발판 | 일반 발판과 유사하되, 움직임을 암시하는 시각적 표시(테두리 등) 필요 |
| 무너지는 발판 | 밟기 전/후 상태가 구분되도록 균열 등 표시 |
| 스탯 변화 발판 | 버프/디버프 효과를 색으로 구분 (버프=긍정적 색, 디버프=부정적 색이되 위험 색(빨강)과는 다르게) |

### 9.4 UI (마커, 하트)

| 항목 | 방향 |
|---|---|
| 마커 | 상호작용 가능 대상 위에 표시되는 마커는 6장의 UI 색상군(플레이 색상과 겹치지 않는 흰색/남색 계열 등)을 따르되, 눈에 잘 띄어야 함 |
| 하트(체력) | 화면 상단 등 HUD 영역에 표시, 게임플레이 색상과 겹치지 않게 |
